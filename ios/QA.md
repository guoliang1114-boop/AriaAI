# Aria iOS 验收清单

当前状态：以下是待在 Mac/iOS 模拟器或真机上执行的验收项，不代表已经运行通过。

## 构建
- [ ] 在 Xcode 打开工程，确认 Aria 与 AriaTests 两个目标和共享 scheme 可见。
- [ ] 运行 Debug 模拟器构建，执行全部 51 个 XCTest。
- [ ] 运行 Release 构建并检查编译器警告。

## 进入与退出
- [ ] 首次启动展示启动页、三页引导；左右滑动、页点、下一步、跳过均有效。
- [ ] 下次启动跳到登录；“重新查看功能引导”可以恢复首次路径。
- [ ] 无效邮箱和短密码显示就地错误；模拟凭据可登录。
- [ ] 显示/隐藏密码不会丢失输入；系统不出现麦克风/语音权限请求。
- [ ] 退出后返回登录，邮箱/密码为空，所有未发送草稿/引用清除，已保存历史仍保留。

## 聊天和审批
- [ ] 可发送、复制、长按回复、左滑回复；新消息也有相同动作。
- [ ] 取消引用正确；空消息不能发送；同一会话重复点击不会重复请求。
- [ ] 新建/切换会话相互独立；两个会话可以各自等待回复。
- [ ] 带文字和引用切换、搜索跳转、新建后返回，原会话草稿仍完整。
- [ ] 存在草稿时从详情带回内容，旧文字不丢失；重复带回同一内容不重复插入。
- [ ] 等待回复时继续写下一条，再停止整理，草稿保留；停止后立即重试没有旧回复或旧审批。
- [ ] 阅读历史/搜索命中时收到新回复，阅读位置不变；“新回复”按钮可跳至底部。
- [ ] 搜索新旧消息可跳转；随后打开/关闭状态页不再跳回旧搜索结果。
- [ ] 审批在卡片、详情和状态页显示一致；已决定的审批不能反向改写。
- [ ] 退出时仍在等待的模拟回复不会再进入新会话。

## 语音和电话
- [ ] 语音为白色，三种光球配色明显不同；点击光球/状态条切换。
- [ ] 静音、字幕开关、打断有效；结束回聊天且摘要仅一条。
- [ ] 电话首先出现模拟资费说明；取消不连接。
- [ ] 呼叫中立刻取消，等待超过 1.7 秒后不会重现通话。
- [ ] 连接后计时、静音/免提、键盘显示/隐藏/删除数字与挂断有效。
- [ ] 重复进入通话恢复初始按钮标签和状态；退出后计时停止。
- [ ] 语音进入非活跃状态后计时/光球暂停，回到应用后从原时长继续。
- [ ] 电话呼叫中进入后台会取消；已接通时进入后台会结束并仅生成一次摘要。

## 内容与设置
- [ ] 动态筛选、按钮/下拉刷新与审批状态同步；空状态正确。
- [ ] 刷新后立刻离开并返回，不应用旧刷新结果；新的刷新能正常完成。
- [ ] 灵感换一批与反馈有可见结果。
- [ ] 目标清单更新进度；资料库搜索/类型筛选/空状态/收藏可用。
- [ ] 所有“带回聊天”只预填文字，不自动发送。
- [ ] Gmail 模拟连接开关只改本地页面；返回仍在设置。
- [ ] 设置各行有详情或本地状态反馈；通知不请求系统权限。

## 本地保存与恢复
- [ ] 修改多个会话草稿、引用、审批，等待保存成功；终止并重开后标识/时间/关联/选择保持，仍进入模拟登录。
- [ ] 等待回复时终止并重启，只有已保存发送内容；不自动回复或卡在等待状态，恢复说明可见。
- [ ] 写入失败时主页面提示可进入数据控制；当前内容保留，修复条件后重试成功，状态准确。
- [ ] 损坏、未知 schema、超限或关联无效的 JSON 不被自动覆盖；编辑、重试、退出后检查原文件字节未变。
- [ ] 无临时改动时可重试读取；有临时改动时不允许旧记录覆盖当前内容。
- [ ] 退出清除草稿并成功保存后重启，草稿为空但消息/审批保留；写失败时登录页提示仍可重试。
- [ ] 归档重置的确认清楚说明丢弃未保存改动；取消不改动数据，成功后旧文件字节保留且示例状态恢复。
- [ ] 首次无文件时重置，不错误声称存在归档；归档或写入失败时内存内容不变。
- [ ] schema 1 测试格式迁移后首次写入之前产生旧文件归档；再次加载为 schema 2。
- [ ] 100KB 以上草稿可缩短；发送被拒后草稿仍在；接近容量时新建/通话摘要不使历史进入不可保存状态。
- [ ] 检查快照和归档均无登录邮箱/密码/令牌；目录排除备份，设备锁定文件保护/解锁后重试行为准确。
- [ ] 用 Xcode 容器检查归档文件；当前没有应用内浏览、恢复或删除归档功能，重启后说明不作为完整归档清单。

## 视觉与可访问性
- [ ] 检查小尺寸 iPhone、大尺寸 iPhone、iPad 横竖屏。
- [ ] 系统深色模式下仍全浅色；底栏与键盘安全区正确。
- [ ] 最大文字尺寸无关键内容截断；引导页脚改为竖向布局，状态/筛选使用菜单。
- [ ] 小屏加大字键盘打开时，输入框/引用/发送仍可见，收起键盘操作可达。
- [ ] VoiceOver 可操作图标、页点、审批、消息自定义动作与通话按钮。
- [ ] 开启“减弱动态效果”后，语音光球减少动画。
- [ ] 所有核心按钮有至少 44pt 的可点击区域。
