# Aria iOS 验收清单

当前状态：以下是待在 Mac/iOS 模拟器或真机上执行的验收项，不代表已经运行通过。

## 构建
- [ ] 在 Xcode 打开工程，确认 Aria 与 AriaTests 两个目标和共享 scheme 可见。
- [ ] 运行 Debug 模拟器构建，执行全部 12 个 XCTest。
- [ ] 运行 Release 构建并检查编译器警告。

## 进入与退出
- [ ] 首次启动展示启动页、三页引导；左右滑动、页点、下一步、跳过均有效。
- [ ] 下次启动跳到登录；“重新查看功能引导”可以恢复首次路径。
- [ ] 无效邮箱和短密码显示就地错误；模拟凭据可登录。
- [ ] 显示/隐藏密码不会丢失输入；系统不出现麦克风/语音权限请求。
- [ ] 退出后返回登录，邮箱/密码为空，旧会话输入与模拟状态清除。

## 聊天和审批
- [ ] 可发送、复制、长按回复、左滑回复；新消息也有相同动作。
- [ ] 取消引用正确；空消息不能发送；同一会话重复点击不会重复请求。
- [ ] 新建/切换会话相互独立；两个会话可以各自等待回复。
- [ ] 搜索新旧消息可跳转；随后打开/关闭状态页不再跳回旧搜索结果。
- [ ] 审批在卡片、详情和状态页显示一致；已决定的审批不能反向改写。
- [ ] 退出时仍在等待的模拟回复不会再进入新会话。

## 语音和电话
- [ ] 语音为白色，三种光球配色明显不同；点击光球/状态条切换。
- [ ] 静音、字幕开关、打断有效；结束回聊天且摘要仅一条。
- [ ] 电话首先出现模拟资费说明；取消不连接。
- [ ] 呼叫中立刻取消，等待超过 1.7 秒后不会重现通话。
- [ ] 连接后计时、静音/免提、键盘显示/隐藏/删除数字与挂断有效。
- [ ] 重复进入通话恢复初始按钮标签和状态；退出后计时停止。

## 内容与设置
- [ ] 动态筛选、按钮/下拉刷新与审批状态同步；空状态正确。
- [ ] 灵感换一批与反馈有可见结果。
- [ ] 目标清单更新进度；资料库搜索/类型筛选/空状态/收藏可用。
- [ ] 所有“带回聊天”只预填文字，不自动发送。
- [ ] Gmail 模拟连接开关只改本地页面；返回仍在设置。
- [ ] 设置各行有详情或本地状态反馈；通知不请求系统权限。

## 视觉与可访问性
- [ ] 检查小尺寸 iPhone、大尺寸 iPhone、iPad 横竖屏。
- [ ] 系统深色模式下仍全浅色；底栏与键盘安全区正确。
- [ ] 最大文字尺寸无关键内容截断；引导页脚改为竖向布局。
- [ ] VoiceOver 可操作图标、页点、审批、消息自定义动作与通话按钮。
- [ ] 开启“减弱动态效果”后，语音光球减少动画。
- [ ] 所有核心按钮有至少 44pt 的可点击区域。
