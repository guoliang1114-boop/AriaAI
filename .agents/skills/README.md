# Curated AriaAI skills for Codex

This directory exposes a deliberately small, high-value subset of AriaAI's
canonical `skills/` catalog through Codex's repository skill discovery path.
Entries are relative symbolic links so there is only one maintained copy of
each `SKILL.md` and its supporting assets.

Selection criteria:

- broadly useful across professional knowledge-work projects;
- clear input/output and verification contracts;
- representative of AriaAI's document, analysis, meeting, and visualization
  workflows without loading the entire catalog into every agent context.

Add a skill here only after its description is concise and its workflow has a
repeatable validation path. The full catalog remains available to AriaAI's own
skill registry under `skills/`.
