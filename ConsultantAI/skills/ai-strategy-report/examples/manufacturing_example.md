# 示例：ABC 制造公司 AI 战略规划

完整的使用示例，展示从输入到输出的全过程。

## 用户输入

### 客户基本信息
- **公司名称**：ABC智能制造有限公司
- **所属行业**：工业制造（汽车零部件）
- **公司规模**：800员工 / 年收入8亿人民币
- **当前数字化水平**：中级（已上ERP，有部分自动化设备）

### 业务背景
- **核心业务**：汽车发动机零部件生产
- **当前面临的主要挑战**：
  1. 质检依赖人工，漏检率约3%，导致客户投诉
  2. 设备故障突发，平均停机损失10万/小时
  3. 库存周转慢，积压资金约3000万
- **希望AI解决**：质检自动化、预测性维护、需求预测

### 战略方向
- [x] 降本增效（质检自动化减少50%人工）
- [x] 风险管控（设备故障预测，降低停机）
- [x] 运营优化（库存优化，释放现金流）

### 已知信息
- **已有数据资产**：
  - 3年设备传感器数据（温度、振动、电流）
  - 5年历史质检记录（含缺陷照片）
  - 10年订单和销售数据
- **已有技术基础**：阿里云、现有MES系统
- **预算范围**：首年500万，后续每年300万
- **时间表要求**：6个月内看到试点效果

### 特别关注点
- 质检准确率需要从97%提升到99.5%
- 设备预测准确率希望达到85%以上
- 数据可以上云，但核心工艺参数需加密
