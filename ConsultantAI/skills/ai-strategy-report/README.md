# AI战略报告

基于 **KPMG咨询风格模板** 生成完整的AI战略报告PPT（15+页），分析企业数字化现状、识别高价值AI场景、制定实施路线图、提供ROI预测。

**模板来源**: `assets/KPMG-Template.pptx`

---

## 功能概览

| 特性 | 说明 |
|------|------|
| **报告体量** | 15页完整战略报告 |
| **分析框架** | 数字化成熟度 × 业务价值 2×2 矩阵 |
| **实施路线** | 3阶段规划（0-6月/6-18月/18-36月） |
| **财务预测** | 3年投资与ROI分析 |
| **输出格式** | PowerPoint (.pptx) 专业演示文稿 |

---

## 快速开始

### 典型调用示例

```
为ABC制造公司生成AI战略报告，核心痛点是质检人工成本高、设备故障频发，希望实现质检自动化和预测性维护。
```

```
生成零售行业的AI战略规划，重点在需求预测和个性化推荐，现有5年历史销售数据。
```

### 输出结构

```
writing_outputs/YYYYMMDD_HHMMSS_ai_strategy_[公司名]/
├── AI_Strategy_Report.pptx      # 主报告文件
├── AI_Strategy_Data.json        # 结构化数据（可选）
└── summary.md                   # 执行摘要
```

## 报告结构（15页）

```
Slide 1:  封面
Slide 2:  执行摘要
Slide 3-4: 现状评估（数字化成熟度、数据基础、能力画像）
Slide 5-6: AI机会地图（2×2 价值-可行性矩阵）
Slide 7-9: 重点场景详解（3个优先级场景）
Slide 10-11: 实施路线图（Phase 1/2/3）
Slide 12: 投资与回报分析
Slide 13: 组织能力（人才、架构、平台）
Slide 14: 风险与应对
Slide 15: 下一步行动（30天计划）
```

## 输入要求

### 必填信息

```markdown
**客户基本信息**
- 公司名称：
- 所属行业：
- 公司规模（员工数/收入）：
- 当前数字化水平（初级/中级/领先）：

**业务背景**
- 核心业务/产品：
- 当前面临的主要挑战：
- 希望AI解决的核心问题：

**战略方向**（可多选）
- [ ] 降本增效
- [ ] 增收增长
- [ ] 体验提升
- [ ] 创新探索
- [ ] 风险管控
```

### 可选信息

```markdown
**数据资产**
- 已有数据类型：客户数据、交易数据、IoT数据等
- 数据历史：如3年传感器数据

**技术基础**
- 云平台：阿里云/AWS/自有服务器
- 现有系统：ERP、MES、CRM等

**约束条件**
- 预算范围：百万级/千万级
- 时间表：如6个月内看到试点效果
- 特殊限制：如数据不能上云
```

## 使用提示

### ✅ 获得最佳效果

- 提供具体的业务痛点（"质检漏检率3%"而非"想提升质量"）
- 说明现有数据情况（"有3年历史传感器数据"）
- 标注预算范围和时间要求
- 说明特殊限制条件

### ❌ 避免

- 过于笼统的需求（"帮我们做AI转型"）
- 隐瞒关键约束（如数据合规要求）
- 期望立即获得技术选型建议
