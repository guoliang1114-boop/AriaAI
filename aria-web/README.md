# Aria AI Web

轻量、快速、灵动的 Aria AI 网页版本。

## 技术栈

- **框架**: React 18 + TypeScript
- **构建工具**: Vite
- **样式**: Tailwind CSS
- **路由**: React Router v6
- **图标**: Lucide React

## 开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```

## 项目结构

```
src/
├── components/     # 通用组件
│   └── Sidebar.tsx
├── pages/          # 页面组件
│   ├── Login.tsx
│   └── Chat.tsx
├── utils/          # 工具函数
├── App.tsx         # 主应用组件
├── main.tsx        # 入口文件
└── index.css       # 全局样式
```

## 特性

- 🎨 现代化 UI 设计，支持暗黑模式
- ⚡ 流畅的动画和交互
- 📱 响应式布局
- 🔒 基于 Token 的认证
- 💬 实时流式对话
- 🎯 快速操作和快捷入口
