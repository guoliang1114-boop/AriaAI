# Skill 交付物总表

> 日期：2026-05-31
> 目的：把 48 个 Skill 的 `Deliverable Catalog` 汇总成统一服务货架，便于产品页面展示、项目资产保存、知识库归档和后续交付物选择器设计。

---

## 1. 使用原则

每个 Skill 都不应只输出一段回答，而应根据用户所处阶段选择合适交付物：

| 阶段 | 默认交付物类型 |
|------|----------------|
| 方向不清 | 诊断 memo、问题树、资料清单、初步机会判断 |
| 方案设计 | 方案报告、选项比较、价值测算、路线图 |
| 执行推进 | 工作计划、行动清单、责任矩阵、风险台账、跟踪表 |
| 高层沟通 | Executive deck、committee pack、decision memo |
| 留痕归档 | 底稿、证据索引、计算模型、复核清单、项目记忆 |

交付物选择规则：

1. 用户明确要求格式时，优先满足用户格式。
2. 用户只问方向时，默认输出 memo 或 one-pager。
3. 用户要求推进项目时，默认输出 roadmap、tracker、checklist 或 tasks。
4. 用户要求汇报时，默认输出 PPT deck 或 committee pack。
5. 用户涉及金额、税负、估值、ROI、现金流时，必须输出或建议 Excel model。
6. 用户涉及审计、合规、税务争议、调查时，必须输出 evidence / workpaper / register 类交付物。

## 3. 产品化建议

后续在 Aria 产品里可以把交付物做成三个层级：

1. **Skill 页面展示**：每个 Skill 展示 3-8 个可交付资产，用户可直接选择。
2. **对话中自动推荐**：模型根据用户问题阶段自动推荐一个默认交付物。
3. **项目资产保存**：交付物生成后保存为项目文档、任务、Excel、PPT、客户记忆或知识库素材。

建议交付物元数据字段：

```yaml
deliverable:
  name: "Executive strategy deck"
  format: "PPT"
  stage: "高层沟通"
  skill: "digital-strategy"
  save_to: "project_documents"
  memory_policy: "summarize_to_project_memory"
  requires_review: true
```
