## 1. 系统总览

```mermaid
flowchart LR
    U[User]

    subgraph MAC[macOS Client]
        SWIFT[SwiftUI Views]

    subgraph WEB[Web Client]
        REACT[React Pages]
        AUTH[AuthContext]

        I18N[i18n]
    end

    subgraph BE[FastAPI Backend]
        MAIN[main.py]
        MW[Auth Middleware]
        ROUTERS[Routers]
        CTX[context_builder.py]
        SERVICES[LLM / RAG / Scheduler]
        TOOLS[Tool Registry]
        MODELS[SQLModel Models]

    end

    subgraph DATA[Data]
        DB[(SQLite / PostgreSQL)]
        FILES[(uploads/)]

    end

    LLM[Claude / Kimi / BigModel]

    U --> MAC
    U --> WEB
    SWIFT --> STORE --> MACAPI --> MAIN
    REACT --> AUTH
    REACT --> I18N
    REACT --> API_CFG --> WEBAPI --> MAIN

    ROUTERS --> CTX
    ROUTERS --> SERVICES

    SERVICES --> KEYRING

    CONFIG --> SERVICES
```

## 3. 当前架构特征

- 双客户端共享同一套后端 API
- 后端配置已开始集中
- 聊天上下文组装已从 `chat.py` 拆出
- Web API 配置已统一到单一模块
- 运行产物开始从仓库中清出

---

## 4. 当前架构风险

- `chat.py` 仍然偏重
- 枚举与标签仍未完全收敛
- 默认配置仍偏开发环境
- 残余乱码影响长期维护
