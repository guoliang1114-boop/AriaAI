# AriaAI 代码问题清单

> 更新日期：2026-04-12
> 范围：按当前最新主线代码重新整理

---

## 1. 最高优先级问题

### 1.1 残余乱码仍然广泛存在

位置：

- `aria-web/src/pages/chat/Chat.tsx`
- `aria-web/src/pages/settings/AISettings.tsx`
- `aria-web/src/types/enums.ts`
- `AriaAI/backend/app/models/db.py`
- `AriaAI/backend/app/services/context_builder.py`

问题：

- 仍有明显 mojibake，且部分已进入用户可见文案

影响：

- 用户体验受损
- i18n 难以收敛
- 类型标签和状态显示容易继续漂移

建议：

- 优先清理用户可见文本
- 再清理注释和历史字符串

### 1.2 `chat.py` 仍然偏重

位置：

- `AriaAI/backend/app/routers/chat.py`

现状：

- 已经把上下文组装拆到 `context_builder.py`
- 已把 provider 选择拆到 `provider_selector.py`
- 已把标题生成拆到 `title_generator.py`

但仍然承担：

- SSE 流
- 历史消息
- 工具执行链路
- 持久化
- 导出接口

影响：

- 仍然是高复杂度核心文件

建议：

- 继续把导出、消息持久化、stream orchestration 分层

### 1.3 枚举和值仍未完全前后端对齐

位置：

- `aria-web/src/types/enums.ts`
- `aria-web/src/types/index.ts`
- `AriaAI/backend/app/models/db.py`

问题：

- 已开始集中枚举
- 但标签层仍有乱码，部分状态约定仍依赖手工同步

建议：

- 以后端值为准
- 前端只维护展示映射

### 1.4 RAG 仍然是 baseline 实现

位置：

- `AriaAI/backend/app/services/rag.py`
- `AriaAI/backend/app/services/context_builder.py`

现状：

- 已支持结构化引用结果
- 但 embedding 仍存为 JSON
- 检索仍以本地相似度 top-k 为主

建议：

- 后续引入 metadata filter、rerank、向量索引

## 2. 中优先级问题

### 2.1 默认配置仍偏开发环境

位置：

- `aria-web/src/config/api.ts`
- `AriaAI/backend/app/config.py`

问题：

- 虽然配置已经统一
- 但默认值依然明显偏开发模式

建议：

- 明确 dev/prod 模式
- 在 UI 中展示当前生效来源

### 2.2 设置体系已经分层，但产品侧尚未完全跟上

位置：

- `AriaAI/backend/SETTINGS_HIERARCHY.md`
- `AriaAI/backend/app/routers/settings.py`
- `aria-web/src/pages/settings/*`

问题：

- 代码层面已经明确三层设置体系
- 但前端设置页和用户心智还未完全匹配这种层级

建议：

- 在 UI 中区分部署配置、系统默认、运行时设置

### 2.3 导出功能已经落地，但仍需统一体验

位置：

- `aria-web/src/pages/chat/Chat.tsx`
- `aria-web/src/pages/projects/ProjectDetail.tsx`
- `AriaAI/backend/app/routers/chat.py`

问题：

- 功能已经有了
- 但导出入口、错误提示、下载反馈仍可继续收敛
