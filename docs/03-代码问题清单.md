## 1. 当前判断

当前主要矛盾已经不再是“页面文件太大”，而是：
- AI 能力是否真正被业务用户看见并稳定使用
- 项目记忆和客户记忆是否形成长期资产
- 异步任务、缓存、限流、预算是否足够产品化
- 安全和部署链路是否足够稳

已基本完成：
- `projects` 目录的大型页面结构化重构
- 项目聊天里的 artifacts / references / tool calls 展示
- 项目级三层记忆 V1
- 客户级第四层记忆第一阶段系统化管理
