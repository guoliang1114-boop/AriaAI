## 1. 项目定位

AriaAI is an open-source agentic workspace for professional knowledge work.

It explores how AI systems can maintain long-lived project memory, client context, reusable skills, knowledge workflows, human-in-the-loop approvals, and auditable agent runs for complex professional work. AriaAI is not positioned as a SaaS dashboard or a generic chatbot. It is an open experiment in AI-native workspace infrastructure.

## 2. 简短项目描述

AriaAI is an open-source agentic workspace for professional knowledge work, combining project memory, client memory, reusable skills, knowledge retrieval, human-in-the-loop approvals, and auditable AI runs.

## 3. 为什么它适合 OSS

AriaAI investigates a reusable pattern for AI-native workspaces: persistent context, business objects, reusable workflows, knowledge retrieval, tool execution, approvals, and artifact generation. These are common problems across many professional domains, not only consulting. The repository provides an open reference implementation for how AI applications can move beyond one-off chat into durable, context-aware work systems.

### What does the project do?

AriaAI is an open-source agentic workspace for professional knowledge work. It combines project memory, client memory, skill-based workflows, knowledge retrieval, tool use, human-in-the-loop approvals, and generated artifacts into a workspace where AI can support durable professional delivery rather than isolated prompt responses.

### Why is it important?

Most AI products are still optimized for single-turn chat. AriaAI explores the next layer: AI systems that understand long-running projects, client context, reusable methods, knowledge assets, and reviewable work outputs. The project can serve as an open reference for building AI-native workspaces with persistent memory, auditable agent runs, and human-controlled tool execution.

It would be especially useful for safely refactoring agent runtime logic, increasing test coverage, improving issue triage, and turning product design documents into reliable implementation.
