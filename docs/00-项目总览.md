# AriaAI 项目总览

更新日期：2026-04-18

## 1. 项目定位

AriaAI 是一套面向咨询与交付团队的 AI 协作工作台。

它不是单纯的聊天应用，而是把以下能力组织到同一条工作流里：

- 项目工作台：概览、聊天、记忆、笔记、待办、里程碑、财务、文档
- 客户管理与客户级记忆
- Skills 与业务模板
- 知识库与 RAG
- 生成物与工具调用可视化
- 调度任务与后台异步处理

当前日常开发主线：

- Web 客户端：`aria-web`
- Python 后端：`AriaAI/backend`
- PostgreSQL 数据库

## 2. 当前已落地的核心能力

### 2.1 用户与安全

- 邮箱密码登录
- `X-Auth-Token` 鉴权
- 多设备 Token 管理
- 用户管理、启停用、密码重置
- 登录失败限流
- 弱默认 `JWT_SECRET` 启动拦截

### 2.2 项目工作台

- 项目 CRUD 与阶段流转
- 项目详情聚合接口
- 项目成员、里程碑、待办、财务、文档、笔记
- 项目概览页 AI 总结
- 项目级 `Memory` 页面

### 2.3 项目聊天

- SSE 流式输出
- 工具调用支持
- 标题生成
- Markdown / PDF 导出
- 项目上下文注入
- 知识范围切换：项目 / 客户 / 全局
- RAG 引用来源展示
- 工具调用状态卡片
- 生成物卡片与下载

### 2.4 生成物与知识库

- 项目级 artifacts 管理与下载
- 知识文档上传、向量化、检索
- 文档按客户 / 项目双维度归属

### 2.5 记忆系统

#### 项目级三层记忆

- 原始项目数据
- 结构化项目记忆 `context_memory_json`
- 多视角摘要缓存

#### 客户级第四层记忆

- `client_memory_json`
- 项目变更带脏客户记忆
- 客户级摘要与提升入口
- 系统设置中的 `Client Memory Manager`

### 2.6 系统设置

- AI 模型配置
- 服务器配置
- 语言切换
- 用户管理
- `Project Memory Manager`
- `Client Memory Manager`

## 3. 技术栈

| 层 | 技术 |
|---|---|
| 前端 | React 19、TypeScript、Vite、React Router、i18next |
| 后端 | FastAPI、Uvicorn |
| ORM | SQLModel |
| 数据库 | PostgreSQL / SQLite（本地 fallback） |
| 迁移 | Alembic |
| LLM | Claude、Kimi、BigModel、DeepSeek（预留） |
| RAG | fastembed + 余弦相似度检索 |
| 调度 | APScheduler |

## 4. 当前阶段判断

当前项目已经从“基础页面搭起来”进入“AI 能力工程化”阶段。

最明显的变化有三条：

1. 聊天不再只是问答，而是具备引用、工具、生成物和持久化元数据。
2. 项目记忆已经不是实验功能，而是贯穿概览、聊天、设置和系统管理页的基础设施。
3. 客户记忆已经从文档设想推进到可用 V1，但仍有继续产品化空间。
