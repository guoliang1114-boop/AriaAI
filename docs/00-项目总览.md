> 版本：v3.2
> 更新日期：2026-04-12
> 说明：基于当前 `main` 最新代码整理

---

## 1. 项目定位

AriaAI 是面向咨询顾问和专业服务团队的 AI 工作台。它不是单一聊天工具，而是围绕项目、客户、知识、技能、模板、定时任务和交付物组织工作流。

当前仓库包含三套主要系统：

- `AriaAI/AriaAI`：SwiftUI macOS 客户端
- `aria-web`：React + TypeScript Web 客户端
- `AriaAI/backend`：FastAPI + SQLModel 后端

## 5. 当前配置体系

### 5.1 后端

后端当前由 `AriaAI/backend/app/config.py` 统一管理：

- `DATABASE_URL`
- provider 默认值
- 默认模型
- RAG 配置
- CORS 配置
- 缓存 TTL
- Scheduler 开关
- Claude / Kimi / BigModel base URL

并通过 `backend/.env` 与 `.env.production` 支撑部署配置。

### 5.2 配置分层

仓库已经显式给出三层设置体系：

1. 部署配置：环境变量 / `.env`
2. 代码默认值：`app/config.py`
3. 运行时用户设置：`Setting` 表

说明文档位于：

- `AriaAI/backend/SETTINGS_HIERARCHY.md`

### 5.3 Web

Web 当前通过 `aria-web/src/config/api.ts` 统一 API 基地址：

优先级：

1. `localStorage.serverUrl`
2. `VITE_API_URL`
3. 默认 `http://127.0.0.1:8000`

`axios client` 和聊天页流式请求都已切到这个统一入口。

## 6. 当前状态判断

当前系统最明显的积极变化是：

- 配置开始有单一来源
- 聊天上下文、provider 选择、标题生成开始模块化
- RAG 开始支持结构化引用
- Web 功能已从“能聊天”进入“能导出、能沉淀、能项目化协作”

当前仍然最值得优先关注的问题：

- 残余乱码
- 枚举与标签收敛
- `chat.py` 仍偏重
- 默认配置仍偏开发环境
- RAG 仍是 baseline
