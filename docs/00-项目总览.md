# AriaAI 项目总览

更新日期：2026-04-14

## 1. 项目定位

AriaAI 当前是一套面向咨询类团队的 AI 协作工作台，不只是聊天工具，而是把项目、客户、知识库、技能、文档和交付动作组织到同一套工作流中。

当前主形态已经明确为：
- Web 客户端：`aria-web`
- Python 后端：`AriaAI/backend`
- PostgreSQL 数据库

仓库中仍保留部分历史资产，但目前日常开发与交付主线都围绕 Web + FastAPI 展开。

## 2. 当前已落地能力

### 2.1 认证与用户

- 邮箱密码登录
- `X-Auth-Token` 鉴权
- `UserToken` 多设备 token
- 用户列表、启停用、重置密码

### 2.2 项目工作台

- 项目 CRUD
- 项目详情聚合接口 `GET /projects/{id}/detail`
- 里程碑、财务、成员、文件夹、文件管理
- 项目上下文摘要生成

### 2.3 项目聊天

- 项目对话与普通工作台对话分离
- SSE 流式输出
- 标题生成
- Markdown / PDF 导出
- 项目上下文注入
- 知识范围切换：
  - 当前项目
  - 当前客户
  - 全局知识库

### 2.4 项目文档工作区

- 左侧 Markdown 目录树
- 右侧编辑 / 预览 / 分栏
- 新建、重命名、删除文档
- AI 润色
- 默认咨询售前模板
- 聊天内容可沉淀为 Markdown 文档

### 2.5 项目待办

- 项目内待办 CRUD
- 指派负责人
- 截至日期
- 仪表盘“我的待办”跨项目聚合

### 2.6 客户与知识库

- 客户 CRUD
- 客户详情页与关联项目查看
- 知识库文档上传、向量化、检索
- `KnowledgeDocument.project_id` / `client_id` 维度隔离

### 2.7 技能与模板

- Skill CRUD
- 模板管理
- 调度任务管理
- 生成文件能力

## 3. 当前技术栈

| 层 | 技术 |
|---|---|
| 前端 | React 19、TypeScript、Vite、React Router、i18next |
| 后端 | FastAPI、Uvicorn |
| ORM | SQLModel |
| 数据库 | PostgreSQL |
| 迁移 | Alembic |
| LLM | Claude、Kimi、BigModel |
| RAG | fastembed + 本地 cosine similarity |
| 文件生成 | python-pptx、python-docx、openpyxl、reportlab |
| 调度 | APScheduler |

## 6. 当前架构判断

当前代码已经从“功能验证期”进入“工作台深化 + 结构收敛期”。

比较成熟的部分：
- 认证与基础项目工作台
- 项目聊天主链路
- 项目文档工作区
- 待办与跨项目提醒
- 知识库范围隔离

最值得持续关注的风险：
- `projects.py` 仍然承载过多项目域逻辑
- `ProjectDetail.tsx` 仍然偏大，UI 和数据逻辑耦合较重
- 线上数据库迁移流程需要更稳定的 guard rail
- 历史文档和少量页面仍有编码遗留问题

## 7. 近期重要变更

- 默认数据库切换为 PostgreSQL
- 补齐 Alembic 迁移链路
- 项目聊天知识范围隔离
- 咨询售前项目文档模板
- 待办支持截至日期
- 仪表盘展示“我的待办”日期
