# AriaAI 项目总览

更新日期：2026-04-15

## 1. 项目定位

AriaAI 当前是一套面向咨询类团队的 AI 协作工作台。

它不是单纯的聊天应用，而是把以下几类能力组织到同一套工作流里：
- 项目
- 客户
- 知识库
- 项目文档
- 待办事项
- Skills 与模板
- 生成与导出

当前日常开发主线已经收敛到：
- Web 客户端：`aria-web`
- Python 后端：`AriaAI/backend`
- PostgreSQL 数据库

仓库中仍保留部分历史资产，但当前真实交付路径已经是 Web + FastAPI + PostgreSQL。

## 2. 当前已经落地的能力

### 2.1 认证与用户

- 邮箱密码登录
- `X-Auth-Token` 鉴权
- 多 token 管理
- 用户列表、启停用、密码重置

### 2.2 项目工作台

- 项目 CRUD
- 项目详情聚合接口 `GET /projects/{id}/detail`
- 项目成员、文件夹、文件、里程碑、财务信息
- 项目概述与上下文摘要

### 2.3 项目聊天

- 项目对话与普通工作台对话分离
- SSE 流式输出
- 标题生成
- Markdown / PDF 导出
- 项目上下文注入
- 知识范围切换
  - 当前项目
  - 当前客户
  - 全局知识库

### 2.4 项目文档工作区

- 左侧 Markdown 文档树
- 右侧编辑 / 预览 / 分栏
- 默认预览模式
- 新建、重命名、删除
- AI 润色
- AI 润色流式返回
- 咨询类售前模板初始化
- 聊天内容可沉淀为 Markdown 文档

### 2.5 项目待办

- 项目内待办 CRUD
- 指派负责人
- 截止日期
- “我的待办”跨项目聚合
- 仪表盘显示截止日期

### 2.6 客户与知识库

- 客户 CRUD
- 客户详情与关联项目
- 知识文档上传、向量化、检索
- `KnowledgeDocument.client_id`
- `KnowledgeDocument.project_id`
- 项目级知识隔离

### 2.7 Skills 与生成能力

- Skill CRUD
- 模板管理
- 调度任务
- 生成文件

## 3. 当前技术栈

| 层 | 技术 |
|---|---|
| 前端 | React 19、TypeScript、Vite、React Router、i18next |
| 后端 | FastAPI、Uvicorn |
| ORM | SQLModel |
| 数据库 | PostgreSQL |
| 迁移 | Alembic |
| LLM | Claude、Kimi、BigModel |
| RAG | fastembed + 本地相似度检索 |
| 文件生成 | python-pptx、python-docx、openpyxl、reportlab |
| 调度 | APScheduler |

## 6. 当前阶段判断

当前代码已经从“单点能力验证”进入“工作台深化 + 结构收敛”的阶段。

已经比较成型的部分：
- 基础认证
- 项目工作台主链路
- 项目聊天
- 项目文档工作区
- 项目待办
- 知识范围隔离

需要持续关注的部分：
- `projects.py` 过于集中
- `ProjectDetail.tsx` 过于集中
- 部署时数据库迁移容易和真实表结构脱节
- 少量中文编码污染仍在影响可维护性

## 7. 最近一轮重要变化
