# AriaAI 项目总览

> 版本：v3.1
> 更新日期：2026-04-12
> 说明：基于当前 `main` 最新代码整理

---

## 1. 项目定位

AriaAI 是面向咨询顾问和专业服务团队的 AI 工作台。它不是单纯的对话应用，而是围绕项目、客户、知识、技能、模板、定时任务和交付物组织工作流。

当前仓库包含三套主要代码：

- `AriaAI/AriaAI`：SwiftUI macOS 客户端
- `aria-web`：React + TypeScript Web 客户端
- `AriaAI/backend`：FastAPI + SQLModel 后端

---

这轮 GitHub 更新最值得记录的变化有：

## 6. 当前配置方式

### 6.1 后端

后端当前由 `AriaAI/backend/app/config.py` 统一管理：

- `DATABASE_URL`
- provider 默认值
- 默认模型
- RAG 配置
- CORS 配置
- 缓存 TTL
- Scheduler 开关
- Claude / Kimi / BigModel base URL

同时自动读取 `backend/.env`。

### 6.2 Web

Web 当前通过 `aria-web/src/config/api.ts` 统一 API 基地址：

优先级：

1. `localStorage.serverUrl`
2. `VITE_API_URL`
3. 默认 `http://127.0.0.1:8000`

`axios client` 与聊天页流式请求都已切到这个统一入口。
