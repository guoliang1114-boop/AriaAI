# AriaAI 项目总览

更新日期：2026-04-17

## 1. 项目定位

AriaAI 是一套面向咨询类团队的 AI 协作工作台。

它不是单纯的聊天应用，而是把以下几类能力组织到同一套工作流里：
- 项目工作台（概览 / 聊天 / 笔记 / 待办 / 里程碑 / 财务 / 文件 / 文档）
- 客户管理与知识库
- Skills 与场景模板（含 21 个专业咨询场景）
- 生成物管理（Artifacts，已接入前端）
- 工具调用可视化（ToolCall，已接入前端）
- 调度任务

当前日常开发主线：
- Web 客户端：`aria-web`
- Python 后端：`AriaAI/backend`
- PostgreSQL 数据库

## 2. 当前已经落地的能力

### 2.1 认证与用户

- 邮箱密码登录
- `X-Auth-Token` 鉴权
- 多设备 Token 管理（`UserToken` 表）+ 旧版 `auth_token` 向下兼容
- 用户列表、启停用、密码重置
- 登录接口失败限流（`LOGIN_RATE_LIMIT_ATTEMPTS` / `LOGIN_RATE_LIMIT_WINDOW_SECONDS`）
- 弱默认 `JWT_SECRET` 启动拦截（可通过 `ALLOW_INSECURE_JWT_SECRET=true` 在本地豁免）
- 三层配置体系（DB runtime → 代码默认 → 环境变量）

### 2.2 项目工作台

- 项目 CRUD，状态流转（lead / opportunity / won / delivering / archived）
- 项目列表按阶段分组展示（`ProjectsPhaseSection` + 看板卡片）
- 项目详情聚合接口 `GET /projects/{id}/detail`（单次查询返回全量数据）
- 项目成员、文件夹、文件（含 AI 自动摘要）、里程碑
- 财务管理（收款 / 支出 / 里程碑付款 / 应收款，汇总计算）
- 项目概述与 AI 生成上下文摘要（SSE 流式）
- 项目域各子模块已下沉独立 service（15 个以上独立模块）
- 项目详情页 Tab 导航完全基于 React Router + `projectDetailTabs.ts` 配置驱动

### 2.3 项目聊天

- 项目对话与普通工作台对话分离
- SSE 流式输出 + 工具调用支持
- 标题生成
- Markdown / PDF 导出
- 项目上下文注入（文件 + 里程碑 + 项目摘要）
- 知识范围切换（当前项目 / 当前客户 / 全局知识库）
- **RAG 引用来源展示**：流式回答中同步显示 `references`，最终持久化进 `metadata_json`
- **工具调用状态可视化**：`tool_executing` / `tool_result` 流事件渲染为状态卡片（running / completed / error）
- **生成物卡片**：AI 生成文件时在聊天流中渲染 `ProjectChatArtifactCard`，支持直接下载

### 2.4 项目文档工作区

- 左侧文档树（`ProjectNotesFolderTree` + `ProjectNotesSidebar`）
- 右侧编辑 / 预览 / 分栏（`ProjectNotesContentPanel`）
- 新建、重命名、删除（弹窗 `ProjectNotesDocumentDialog`）
- AI 润色（普通 + 流式，`ProjectNotesAIModal`）
- 咨询类售前模板初始化（9 个预置文档）
- 聊天内容可沉淀为 Markdown 文档（新建 or merge 追加）

### 2.5 项目待办

- 项目内待办 CRUD（`ProjectTodoItem` + `ProjectTodoCreateForm`）
- 指派负责人（`ProjectUserPicker`）
- 截止日期
- "我的待办"跨项目聚合
- 仪表盘显示截止日期

### 2.6 项目概览（Overview Tab）

- 项目信息卡（`ProjectOverviewInfoCard`）
- 里程碑进度卡（`ProjectOverviewMilestonesCard`）
- 项目摘要卡（`ProjectOverviewSummaryCard`）
- 文档卡（`ProjectOverviewDocumentsCard`）
- 笔记卡（`ProjectOverviewNotesCard`）
- **AI 生成物列表**（`ProjectOverviewArtifactsCard`，含下载入口）

### 2.7 客户与知识库

- 客户 CRUD + AI 客户画像建议
- 客户详情与关联项目
- 知识文档上传、向量化、检索（fastembed + 余弦相似度）
- `KnowledgeDocument.client_id` / `project_id` 双维度归属
- 项目级知识隔离

### 2.8 Skills 与生成能力

- Skill CRUD（支持 Claude 标准 tools 格式 `tools_definition_json`）
- 默认咨询 Skill（6 个）+ 专业引导工作流（15 个）
- 模板管理（PPTX / DOCX / PDF）
- 调度任务（APScheduler）
- 生成文件管理（`GeneratedFile` + `artifacts` 路由 + 前端生成物卡片）

### 2.9 API Provider 管理

- 支持 Claude（Sonnet / Opus / Haiku 4.x）、Kimi、BigModel、DeepSeek（预留）
- `/settings` API key 状态查询、保存、删除
- `/chat/test-connection` 和 `/chat/test-model` 连通性测试

| 前端 | React 19、TypeScript、Vite、React Router、i18next |

## 5. 关键代码入口

### 后端

- `AriaAI/backend/main.py`（启动入口，JWT 安全校验，lifespan 管理）
- `AriaAI/backend/app/config.py`（三层配置 + 弱 JWT_SECRET 拦截）
- `AriaAI/backend/app/routers/auth.py`（登录限流 + 多设备 Token）
- `AriaAI/backend/app/routers/chat.py`（SSE 流式 + 工具调用）
- `AriaAI/backend/app/routers/projects.py`（项目域路由入口）
- `AriaAI/backend/app/routers/artifacts.py`（生成物下载）
- `AriaAI/backend/app/services/chat_streaming.py`（SSE + tool_executing / tool_result 事件）
- `AriaAI/backend/app/services/context_builder.py`（上下文组装 + RAG）
- `AriaAI/backend/app/services/project_details.py`（详情聚合）

### 前端

- `aria-web/src/App.tsx`（路由入口）
- `aria-web/src/types/api.ts`（完整类型：ToolCallEvent / GeneratedArtifact / MessageMetadata / StreamEvent）
- `aria-web/src/pages/projects/projectDetailTabs.ts`（Tab 配置和 activeTabId 解析）
- `aria-web/src/pages/projects/ProjectDetail.tsx`（路由壳）
- `aria-web/src/pages/projects/PersistentProjectPanels.tsx`（Chat/Notes/Todos 持久化渲染）

- `aria-web/src/pages/projects/ProjectChatToolCallCard.tsx`（工具调用状态卡片）
