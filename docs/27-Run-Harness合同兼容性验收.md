# Run Harness 合同兼容性验收

日期：2026-09-20。前置运行版本 `03aa470`，前置文档版本 `30e187e`。跟踪 [#70](https://github.com/guoliang1114-boop/AriaAI/issues/70)。本文件在发布完成后补录实际运行版本与 Actions 证据。

## 本轮修复

- 前端原先只核对事件类型和 `run_id`，损坏的嵌套回执、数字或完成身份仍可进入时间线。新增 17 类 Product v1 事件的字段校验，保留兼容性新增字段及旧协议适配。
- 损坏的启动/终态转为明确错误，两处聊天入口均拒绝成功回执。独立聊天原先收到旧 `done` 就关闭流，可能漏掉后续失败；现在读完后再确认成功，结束身份必须匹配启动身份，失败与取消终态不能被旧 `done` 覆盖。
- Skill runtime 归一化原先丢失 `deliverable`。现在保留格式、保存目标、评审要求、业务验证器及三个指纹，同时移除非公开字段。
- 后端事件构造器拒绝非有限进度、布尔数字、非整数任务百分比和无效身份，避免无效 JSON 或看似合法的身份字符串。
- 新增由实际 Python builder 生成的单份合成样本：17 类事件，5 个场景的 32 帧和 37 个枚举变体。前端直接编译 JSON 字面量验证 TypeScript 类型兼容性，再验证解析和时间线状态；后端校验样本新鲜度。部署与数据库回归工作流纳入新检查。
