## 3. 下一版本前端主线

### 3.1 Skill 工作流化（P0）

目标：让 Skill 从“一个可以选择的提示词模板”升级为“项目/客户空间中的动作入口”。

建议任务：

1. 项目页增加“从当前项目启动 Skill”入口。
2. 客户页增加“从当前客户启动 Skill”入口。
3. Skill 启动面板自动显示将带入的上下文：项目记忆、客户记忆、文件、里程碑、待办。
4. Skill 执行结果支持保存为项目文档、项目笔记、客户记忆沉淀。
5. Skill 结果保存后提示刷新项目/客户记忆。

### 3.2 Welcome 今日工作起点（P1）

目标：打开系统后能立刻知道今天最该处理什么。

建议任务：

1. 今日到期/即将到期待办。
2. 即将到期里程碑。
3. 最近失败任务与告警入口。
4. 最近生成物。
5. 最近活跃项目一键进入聊天。

### 3.3 项目概览强化（P1）

目标：Overview 不只是静态信息，而是项目经理的行动面板。

建议任务：

1. 风险、开放问题、下一步行动的记忆摘要卡。
2. 未完成里程碑与待办聚合。
3. 最近 AI 生成物与最近对话结论。
4. 客户记忆关联提示。

### 3.4 Memory Operations V3（P1）

目标：从“查看与重试”进入“批量治理与策略化运营”。

建议任务：

1. 批量选择失败记录。
2. 批量重试、批量忽略、批量打开。
3. 数据库/数据缺失类失败默认需要人工确认。
4. 服务端统计接口接入后替换前端兜底推断。

### 3.5 安全与体验基线（P1）

建议任务：

1. Markdown / XSS 系统复核。
2. 长文本、代码块、链接、图片渲染安全测试。
3. 移动端关键页面巡检。
4. 前端 lint 警告清理。

## 4. 工程原则

- 新能力优先挂到项目/客户工作流里，不做孤立功能页。
- 大页面继续拆分为 hook、card、panel、dialog。
- 任务治理相关页面优先保证信息层级清晰，不堆满数字。
- 记忆系统前端表达要同时显示“来源、版本、更新时间、失败状态”。
- 每个小闭环都应能独立构建、提交、部署。

## 5. 建议执行顺序

1. Skill 工作流化第一阶段：项目/客户空间启动入口。
2. Skill 结果保存到项目文档/笔记/客户记忆。
3. Welcome 今日工作起点。
4. Memory Operations V3 批量治理。
5. Markdown / XSS 复核。
