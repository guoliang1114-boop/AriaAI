# AriaAI Web 版本开发计划

> 更新日期：2026-04-12
> 说明：按最新主线代码状态重写

---

## 1. 当前状态判断

`aria-web` 已经是完整的第一版工作台，而不是原型。

当前已具备：

- 登录与鉴权守卫
- Welcome 工作台
- Chat
- Projects / ProjectDetail / NewProject
- Clients / ClientDetail
- Knowledge
- Skills / SkillForm
- Settings 多子页
- AuthContext / ToastContext / ThemeContext
- i18n
- 统一 API 配置模块 `src/config/api.ts`
- 统一枚举入口 `src/types/enums.ts`

---

## 2. 最近进展

本轮代码里，Web 最重要的变化有：

- API 地址统一到了 `src/config/api.ts`
- Chat 流式请求已改走统一 API 基地址
- AI 设置页加入 BigModel 模型选项
- 类型层开始引入统一枚举

这说明 Web 端的重点已经从“补页面”转向“收敛配置与状态语义”。

---

## 3. 当前最应该做的事

### 3.1 清理残余乱码

优先文件：

- `pages/chat/Chat.tsx`
- `pages/settings/AISettings.tsx`
- `types/enums.ts`

### 3.2 优化默认 API / 服务器切换体验

当前统一入口已经建立，但默认值仍偏本地开发。

建议：

- UI 中明确显示当前使用的是 `serverUrl`、`VITE_API_URL` 还是默认值
- 根据部署模式调整默认策略

### 3.3 收敛页面与组件层级

当前仍有旧页面与新页面并存，需要继续清理不再使用的入口。

### 3.4 强化项目工作台体验

把项目详情页、项目内聊天、项目上下文摘要进一步打通。

---

## 4. 工程侧计划

### 4.1 配置统一

- 完善 `config/api.ts`
- 与 Settings 页逻辑完全对齐

1. 修乱码
2. 优化 API 默认策略与展示

4. 清理旧页面
5. 强化项目工作台与聊天协作体验
