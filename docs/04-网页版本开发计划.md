# Aria AI 网页版本开发计划

## 1. 项目概述

将现有的 macOS SwiftUI 客户端迁移到 Web 平台，使用 React + TypeScript 技术栈，保持与现有 FastAPI 后端的无缝集成。

## 2. 技术选型

### 前端技术栈
| 技术 | 选择 | 理由 |
|------|------|------|
| 框架 | React 18 + TypeScript | 生态成熟，类型安全 |
| 构建工具 | Vite | 极速冷启动，HMR |
| UI 框架 | Tailwind CSS | 原子化 CSS，灵活高效 |
| 组件库 | Radix UI + Headless UI | 无障碍，可定制 |
| 状态管理 | Zustand | 轻量，TypeScript 友好 |
| 路由 | React Router v6 | 标准路由方案 |
| HTTP 客户端 | Axios | 成熟稳定 |
| 图标 | Lucide React | 现代化图标 |
| Markdown | react-markdown + remark | 支持丰富格式 |

## 4. 与后端的集成

### API 接口复用
现有的 FastAPI 后端完全兼容，Web 版本直接使用相同的 RESTful API：

| 模块 | 基础路径 |
|------|----------|
| 认证 | `/auth/*` |
| 对话 | `/chat/*` |
| 项目 | `/projects/*` |
| 知识库 | `/knowledge/*` |
| 技能 | `/skills/*` |
| 设置 | `/settings/*` |

### 认证方式
使用与 macOS 客户端相同的 Token 认证：
- 登录后获取 `auth_token`
- 存储在 `localStorage`
- 通过 `X-Auth-Token` Header 发送

### SSE 流式响应
```typescript
const eventSource = new EventSource(`/chat/conversations/${id}/stream?token=xxx`);
eventSource.onmessage = (event) => {
  const chunk = JSON.parse(event.data);
  // 处理流式数据
};
```

## 6. 开发环境

```bash
# 1. 初始化项目
npm create vite@latest aria-web -- --template react-ts

# 2. 安装依赖
cd aria-web
npm install
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p

# 3. 安装 UI 库和工具
npm install @radix-ui/react-dialog @radix-ui/react-dropdown-menu
npm install lucide-react axios zustand react-router-dom
npm install react-markdown remark-gfm rehype-highlight

# 4. 启动开发服务器
npm run dev
```

## 7. 部署方案

### 构建
```bash
npm run build
```

### Docker 部署
```dockerfile
FROM node:18-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
```

### Nginx 配置
```nginx
server {
    listen 80;
    server_name aria.example.com;
    root /usr/share/nginx/html;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /api {
        proxy_pass http://backend:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```
