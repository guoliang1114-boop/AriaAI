## 3. 当前最该做的事

### 3.1 生成物管理前端接入（P0）

后端 `GeneratedFile` 模型已落地，但前端完全没有接入：

- 在项目页（建议 Documents Tab 内，或新增 Generated Tab）展示 AI 生成文件列表
- 聊天消息中 AI 生成文件时显示文件卡片（名称 + 类型 + 下载按钮）
- 支持直接从生成物下载或预览

### 3.2 RAG 引用来源展示（P0）

聊天的 SSE `references` event 已有数据，但前端表达弱：

- 回答底部渲染引用来源列表（文档名 / 文件名）
- 点击跳转到知识库或项目文件

### 3.3 Welcome 今日感强化（P1）

当前 Welcome 只展示待办列表，缺少工作台的聚焦感：

- 新增"今日到期 / 即将到期里程碑"widget
- 最近活跃项目快速进入聊天入口
- 最近生成物快速访问（配合 3.1）

### 3.4 项目概览强化（P1）

Overview Tab 当前偏静态，建议增加：

- 未完成里程碑和待办的突出展示
- 最近 AI 生成物列表
- 快速进入聊天按钮（附带上下文预填）

## 4. 工程侧建议

### 4.1 配置统一

- 继续以 `src/config/api.ts` 为唯一入口
- 避免新页面重新写相对路径或硬编码 API 前缀

### 4.2 组件边界统一

- 优先抽共享 Hook（数据拉取）和共享组件（UI 原子）
- 新 Tab 通过 `children` 注入 `ProjectDetailLayout`，不再在 Layout 内累积 `isPersistentTab` 判断

### 4.3 持久化 Tab 的扩展原则

当前 Chat / Notes / Todos 通过 `hidden` class 保活，如果新 Tab 也有强状态保活需求（如多步编辑器），才加入持久化列表；否则走 React Router 按需渲染即可。

---

1. 生成物管理前端接入（聊天文件卡片 + 项目生成物列表）
2. RAG 引用来源展示
3. Welcome 今日感强化
4. 项目概览增强
5. Skill 与项目空间联动（Skill 选择器 + 执行结果保存）
