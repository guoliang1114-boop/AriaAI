# AriaAI Web 版本开发计划

> 更新日期：2026-04-14
> 说明：基于当前 `aria-web` 代码状态重写。

---

## 1. 当前状态判断

`aria-web` 已经不是原型，而是一套功能相对完整的工作台前端。当前已具备：

- 登录与鉴权守卫
- Welcome 工作台
- Chat
- Projects / ProjectDetail / NewProject
- 项目 Notes / Todos
- Clients / ClientDetail
- Knowledge
- Skills
- 多子页 Settings
- Toast / Auth / i18n
- 统一 API 配置模块 `src/config/api.ts`
- 共享导出能力 `src/api/chatExport.ts`

## 3. 当前最该做的事

### 3.1 拆分项目详情页

`ProjectDetail.tsx` 已经成为新的复杂度中心，应优先拆分。

### 3.2 收口项目聊天 API 配置

项目页聊天仍残留 `fetch("/api/chat/send")`，需要收口到统一配置。

### 3.3 做一轮乱码治理

Welcome、ProjectDetail、Notes、Todos 等页面还有明显乱码。

### 3.4 补前端交互回归

至少应覆盖：

- 项目 notes 保存
- todos 创建/指派/完成/删除
- 项目聊天与导出
- 设置页服务器地址来源表达

---

## 4. 工程侧建议

### 4.1 配置统一

- 继续以 `src/config/api.ts` 为唯一入口
- 避免新页面重新写相对路径或硬编码 API 前缀

### 4.2 组件边界统一

- 按能力域拆组件，而不是继续堆到页面文件里
- 新增页面时优先抽公共 hook 或 service

### 4.3 文案统一

- 用户可见文本逐步进入 i18n
- 历史乱码优先清理用户可见部分

---

## 5. 建议顺序

1. 拆 `ProjectDetail.tsx`
2. 收口项目聊天请求
3. 清理乱码
4. 补前端主链路测试
5. 再继续增强 Welcome 与项目工作台联动
