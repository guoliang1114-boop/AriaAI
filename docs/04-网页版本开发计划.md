# AriaAI Web 版本开发计划

> 更新日期：2026-04-12
> 说明：按当前最新代码状态重写

---

## 1. 当前状态判断

`aria-web` 已经是完整的第一版工作台，而不是原型。

当前已具备：

- 登录与鉴权守卫
- Welcome 工作台
- Chat
- Projects / ProjectDetail / NewProject
- Clients / ClientDetail
- Knowledge
- Skills / SkillForm
- Settings 多子页
- AuthContext / ToastContext / ThemeContext
- i18n
- 统一 API 配置模块 `src/config/api.ts`
- 统一枚举入口 `src/types/enums.ts`
- 对话导出（Markdown / PDF）

---

## 2. 最近进展

本轮代码里，Web 最重要的变化有：

- API 地址统一到了 `src/config/api.ts`
- Chat 流式请求与导出请求都已走统一 API 基地址
- 项目详情页延续 MBA 风格对话区
- 新增对话导出入口
- AI 设置页加入 BigModel 模型选项
- 枚举与类型进一步收敛
