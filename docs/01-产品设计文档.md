## 1. 产品定位

### 1.1 核心主张

> **不止聊天，搞定一切** — 为顾问团队打造的 AI 原生工作台

管理顾问的工作高度知识密集、交付物标准严苛、客户信息极度敏感。通用 AI 工具（ChatGPT、Claude.ai）解决不了三个问题：

| 问题 | 通用工具的局限 | 本产品的解法 |
|------|--------------|------------|
| **上下文割裂** | 每次对话从零开始，不了解项目背景 | 项目空间 + 知识库，AI 始终知道你在做什么项目 |
| **输出不专业** | 不懂顾问方法论，输出格式不符合要求 | 内置顾问场景技能库，严格遵循 Pyramid Principle 等规范 |
| **数据安全** | 客户数据上传第三方服务器 | 本地运行 + 私有部署，数据不出企业 |

### 1.2 目标用户

| 角色 | 核心诉求 | 使用频率 |
|------|---------|---------|
| **Analyst / Associate** | 快速完成数据整理、PPT 制作、纪要撰写 | 日常高频 |
| **Consultant / Manager** | 框架分析、报告撰写、客户汇报材料 | 日常高频 |
| **Partner / Director** | 提案生成、战略洞察、董事会材料 | 按需使用 |
| **团队管理员** | 管理知识库、模板、技能权限 | 低频维护 |

### 1.3 部署模式

- **阶段一**：Mac 桌面 App（单机使用，本地存储）
- **阶段二**：支持私有化部署（团队共享知识库、模板）
- **阶段三**：SaaS 订阅（面向中小咨询公司，多租户隔离）

### 3.1 技能中心（Skills Hub）

技能分为两个层级，解决粒度不一致的问题：

#### 层级一：快速工具（Quick Tools）
> 5 分钟内完成，单轮或少量多轮交互，输出轻量

#### 层级二：深度任务（Deep Tasks）
> 5-30 分钟，Agent 自主多步执行，输出完整交付物

### 3.2 项目空间（Project Space）

> **核心理念**：顾问的工作以"项目"为单位，而不是以"对话"为单位。

每个项目包含：

| 组成部分 | 内容 |
|---------|------|
| **项目档案** | 客户名称、项目类型、时间周期、团队成员、项目状态 |
| **上下文摘要** | 项目背景、核心问题、关键假设（AI 自动维护，每次对话后更新） |
| **文件库** | 该项目所有输入文件（客户数据、行研报告）和输出文件（PPT、Word） |
| **对话历史** | 该项目下的所有对话，按时间线组织 |
| **任务清单** | 待完成事项、里程碑追踪 |

**项目绑定对话**：在输入框绑定项目后，AI 在回答时自动感知：
- 客户是谁、所在行业
- 项目当前阶段（诊断 / 方案 / 汇报）
- 已有的关键发现和假设

---

### 3.3 知识库（Knowledge Base）

> **核心理念**：让 AI 读你公司的东西，而不是只用通用知识。

#### 知识库内容类型

| 类型 | 示例 | 用途 |
|------|------|------|
| **历史案例** | 过去项目的匿名化报告、方法论总结 | 生成新报告时参考行文风格和结构 |
| **行业研究** | 订阅的行研报告、白皮书、数据库摘要 | 市场分析时引用真实数据 |
| **方法论模板** | 公司标准 PPT 模板、报告结构规范 | 确保输出符合公司风格 |
| **客户资料** | 客户公司介绍、行业背景、往来邮件摘要 | 提案和汇报时精准匹配客户语境 |
| **政策法规** | 行业监管文件、合规要求 | 风险与合规类技能引用 |

#### 知识库功能

- **上传文档**：支持 PDF / Word / Excel / Markdown / 网页链接
- **自动向量化**：上传后自动解析、分块、建立索引（本地 Embedding）
- **RAG 检索**：技能执行时自动检索相关内容，注入 AI 上下文
- **引用标注**：AI 输出内容标注来源文档和段落，可溯源
- **访问控制**（团队版）：知识库按项目或部门隔离，敏感资料权限管控

---

### 3.4 输出模板管理

> 不同团队、不同客户，PPT 和报告的风格要求不同。

- 上传 `.pptx` 母版 / `.docx` 模板 → 绑定到项目或技能
- 技能生成内容时，自动套用对应模板的字体、颜色、页面布局
- 支持多套模板（客户 A 用一套、客户 B 用另一套）

---

### 3.5 定时任务

- 支持自然语言设置（"每周一早 9 点生成本周项目周报"）
- 任务执行时自动调取绑定项目的最新上下文
- 输出文件自动存入对应项目文件库
- 执行完成后发送 macOS 系统通知

## 4. 交互设计

### 4.1 关键用户流程

#### 流程 1：启动一个新项目

```
新建项目 → 填写客户名称 / 行业 / 项目类型
→ 上传背景材料（招股书、行研报告、历史 PPT）
→ 知识库自动解析入库
→ 开始第一个对话，AI 自动感知项目背景
```

#### 流程 2：调用深度技能（以市场研究报告为例）

```
输入框输入 "@市场研究" → 弹出技能配置面板
→ 填写：目标市场 / 研究深度 / 参考知识库范围
→ 发送 → Agent 分解任务步骤（可见）：
   Step 1: 从知识库检索相关行研数据
   Step 2: 联网搜索补充最新数据
   Step 3: 按报告框架生成各章节内容
   Step 4: 套用 PPT 模板排版输出
→ 生成完毕，预览 + 一键下载
```

#### 流程 3：快速工具（以会议纪要为例）

```
上传录音文件 / 粘贴文字记录
→ "@会议纪要" → 发送
→ 30 秒内输出：决策事项 / 行动计划 / 责任人 / 截止日期
→ 一键保存到当前项目
```

## 6. 技术架构

### 6.1 技术栈

| 层 | 选型 | 理由 |
|----|------|------|
| 桌面框架 | **Tauri 2.0** | Rust 后端 + Web 前端，包体小（<10MB），性能好 |
| 前端 | **React 18 + TypeScript** | 生态成熟 |
| UI | **shadcn/ui + Tailwind CSS** | 高质量组件，定制灵活 |
| AI 模型 | **Claude claude-sonnet-4-6**（主力）/ claude-opus-4-6（深度任务）| Anthropic 最新模型 |
| Agent 框架 | **Claude Agent SDK** | 原生工具调用、多步骤任务 |
| 本地向量库 | **LanceDB**（嵌入 Tauri）| 支持本地 Embedding + 向量检索，无需联网 |
| Embedding 模型 | **本地运行的 Nomic Embed**（via Ollama）| 知识库内容不出本机 |
| 本地存储 | **SQLite**（via tauri-plugin-sql）| 对话历史、项目档案、任务记录 |
| 文件操作 | **Tauri fs API** | 限定在工作目录内的安全读写 |
| PPT 生成 | **python-pptx**（sidecar 进程）| 生成 .pptx 文件 |
| PDF 生成 | **Pandoc + WeasyPrint** | 生成格式化 PDF 报告 |

### 6.2 Agent 工具集

```
# 文件操作
read_file(path)             # 读取本地文件
write_file(path, content)   # 写入文件
list_directory(path)        # 列举目录

# 知识库
search_knowledge_base(query, filters)   # 向量检索知识库
get_project_context(project_id)         # 获取项目背景摘要

# 网络
web_search(query)           # 联网搜索（可配置是否开启）
fetch_url(url)              # 抓取指定网页内容

# 文档生成
generate_pptx(outline, template_id)    # 生成 PPT
generate_docx(content, template_id)    # 生成 Word
generate_pdf(content)                  # 生成 PDF
run_data_analysis(code, data_path)     # 执行数据分析脚本

# 系统
send_notification(title, body)         # macOS 系统通知
open_file(path)                        # 在系统默认程序打开文件
```

### 6.3 数据安全设计

| 层面 | 措施 |
|------|------|
| API Key | macOS Keychain 存储，不写入磁盘 |
| 知识库数据 | 本地 LanceDB，Embedding 计算在本机完成，不上传 |
| 对话记录 | SQLite 本地存储，可选 AES-256 加密 |
| 文件操作 | 严格限定在用户指定的工作目录内 |
| 网络请求 | 仅调用 Claude API（可配置走企业代理）和可选的联网搜索 |
| 团队版 | 私有化部署，数据完全在企业内网 |
