```mermaid
flowchart LR
```

## 5. 记忆系统架构

```mermaid
flowchart TD
  ProjectData[项目原始数据] --> ProjectMemory[结构化项目记忆]
  ClientStakeholder[结构化干系人 ClientStakeholder] --> ProjectMemory
  ClientStakeholder --> ClientMemory
  ClientStakeholder --> ChatContext[项目 Chat / Skill 上下文]
  ProjectMemory --> ProjectSummary[项目多视角摘要缓存]
  ProjectMemory --> Promotion[提升/归档沉淀]
  Promotion --> ClientMemory[客户长期记忆]
  ClientMemory --> ClientSummary[客户多视角摘要缓存]
  ProjectMemory --> Jobs[Memory Operations]
  ClientMemory --> Jobs
```

项目记忆存储：

- `Project.context_memory_json`
- `Project.memory_version`
- `Project.memory_stale`
- `Project.memory_rebuild_status`
- `Project.memory_rebuild_failed_at`

客户记忆存储：

- `ClientRecord.client_memory_json`
- `ClientRecord.client_memory_version`
- `ClientRecord.client_memory_stale`
- `ClientRecord.client_memory_rebuild_status`
- `ClientRecord.client_memory_rebuild_failed_at`

结构化干系人（2026-04-21 落地）：

- `ClientStakeholder` 独立实体，字段：姓名、角色、组织层级、影响类型、关系状态、关注点、敏感点、沟通偏好、联系方式、最近动作、备注。
- `stakeholder_contexts.py` 统一序列化，项目记忆 / 客户记忆 / 项目 Chat/Skill 三条链路复用。
- 项目干系人页与客户详情页同源维护（新增、编辑、删除、分组概览）。

任务治理：

- 项目/客户任务统一展示。
- 失败分类与失败明细。
- 重试与取消。
- 预算与告警汇总。
