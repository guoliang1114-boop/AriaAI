# 并购后整合（PMI）规划

## When To Use

- 交易签约后至交割前的整合准备工作
- 交割日（Day 1）的运营连续性保障
- 交割后100天的关键整合行动
- 长期组织、系统、文化整合推进
- 协同效应的追踪和实现

## Tools

- PMI项目管理工具（甘特图、RACI矩阵）
- 协同效应追踪模板
- 文化评估工具（Hofstede/OCAI）
- 系统集成评估矩阵
- 沟通计划模板

## Framework

### 5-Phase PMI Methodology

**Phase 1: Pre-Close Preparation（交割前准备）**
- 整合管理办公室（IMO）组建
- Day 1清单编制
- 沟通策略制定
- 关键人才识别
- IT系统评估
- 法律和监管审批

**Phase 2: Day 1 Execution（交割日执行）**
- 员工沟通（全员信、Town Hall）
- 客户/供应商通知
- 系统访问权限切换
- 品牌/标识变更
- 管理层任命公告
- 法律实体变更登记

**Phase 3: First 100 Days（百日冲刺）**
- 速赢项目（Quick Wins）执行
- 组织架构方案确定
- 关键流程对接
- 系统整合第一阶段
- 文化融合活动启动
- 协同效应项目启动

**Phase 4: Full Integration（全面整合）**
- 组织架构调整落地
- 系统全面整合
- 流程标准化
- 供应链优化
- 人才梯队建设
- 文化融合深化

**Phase 5: Optimization（持续优化）**
- 协同效应达成评估
- 持续改进机制
- 最佳实践推广
- 整合项目收尾
- 经验教训总结

### McKinsey PMI Key Success Factors

- **Speed**：快速决策，避免整合疲劳
- **Talent**：保留关键人才，明确角色
- **Synergy**：聚焦高价值协同效应
- **Culture**：主动管理文化差异
- **Communication**：高频透明沟通

## Workflow

```
1. 交割前准备（T-60至T-0）
   ├─ IMO组建及职责分工
   ├─ 整合范围和优先级确定
   ├─ Day 1清单编制（100+检查项）
   ├─ 沟通策略及材料准备
   ├─ 关键人才保留计划
   └─ IT系统评估及切换方案

2. Day 1执行（T日）
   ├─ 员工沟通执行
   ├─ 客户/供应商通知
   ├─ 系统切换执行
   ├─ 管理层任命
   └─ 运营连续性保障

3. 百日计划执行（T+1至T+100）
   ├─ 速赢项目清单及执行
   ├─ 组织架构方案设计及审批
   ├─ 关键流程对接
   ├─ 系统整合第一阶段
   ├─ 协同效应项目启动
   └─ 周度/月度进展汇报

4. 全面整合（T+101至T+365）
   ├─ 组织架构调整落地
   ├─ 系统全面整合上线
   ├─ 流程标准化推进
   ├─ 供应链整合
   └─ 文化融合项目

5. 持续优化（T+365+）
   ├─ 协同效应达成审计
   ├─ 整合项目收尾
   ├─ 经验教训总结
   └─ 持续改进机制
```

## Diagnostic Questions

1. 交易的预计交割时间是什么？
2. 目标公司的规模（员工数、收入、地域分布）？
3. 买方和目标公司的业务重叠程度？
4. 是否有明确的协同效应预期？
5. 目标公司是否有ERP/核心IT系统？与买方是否兼容？
6. 文化差异的主要表现是什么？

## Verification

- 核对Day 1清单的完整性（覆盖所有关键利益相关方）
- 验证协同效应估算的合理性和可实现性
- 确认组织整合方案的法律合规性
- 检查系统整合的技术可行性
- 评估沟通计划的覆盖度和及时性
