# 示例：B2B 软件标的商业尽调摘要

## 输入摘要

- ARR 1.2 亿元，过去两年增速分别为 42% 和 31%。
- 前五大客户贡献 38%，最大客户合同将在六个月内续签。
- 管理层声称净收入留存率 118%，但尚未提供客户级桥接表。

## 示例结论结构

1. **已支持结论**：历史增长较快，但增速已经回落。
2. **待验证主张**：118% NRR 需要客户级期初、扩张、缩减和流失桥接表支持。
3. **核心风险**：最大客户续签与高集中度可能导致未来十二个月收入波动。
4. **下一步**：执行前二十大客户队列分析、合同复核和流失客户访谈。
5. **交易含义**：在续签完成前，将部分对价与客户留存或 ARR 指标挂钩。

该示例展示证据层级，不代表真实交易建议。
