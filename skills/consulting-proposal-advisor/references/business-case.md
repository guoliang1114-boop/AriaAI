# Business Case

Use this reference when the proposal needs benefit quantification, ROI, pricing logic, or a value case.

## Value Categories

- Revenue: conversion, pricing, retention, cross-sell, sales productivity, market expansion
- Cost: labor efficiency, procurement savings, process automation, waste reduction, system rationalization
- Working capital: inventory turns, receivables, payables, forecasting accuracy
- Risk: compliance exposure, operational resilience, fraud, cyber, safety, service continuity
- Strategic capability: speed to market, decision quality, customer experience, scalability

## Simple Value Model

State the formula and assumptions clearly:

```text
Annual value = baseline volume x improvement rate x unit value
Net value = annual value - one-time implementation cost - recurring operating cost
Payback period = implementation cost / monthly net benefit
```

Use this simple model for early-stage proposals, quick options, and directional value sizing.

## Investment Case Model

Use a more rigorous investment case when the proposal asks for board approval, large technology spend, transformation funding, or multi-year benefits.

```text
Free cash flow by period = incremental cash benefit - implementation cost - recurring cost - tax impact
NPV = sum(free cash flow_t / (1 + discount rate)^t)
IRR = discount rate where NPV = 0
Payback = first period where cumulative net cash flow turns positive
ROI = cumulative net benefit / cumulative investment
```

Show the model as ranges when assumptions are uncertain. Do not imply precision beyond the quality of the inputs.

## Sensitivity Analysis

Use sensitivity analysis when value depends on assumptions such as adoption, conversion, labor productivity, price uplift, retention, or implementation cost.

Recommended output:

- Base case assumptions
- Low/base/high scenario table
- 2-3 biggest value drivers
- Break-even condition
- Sensitivity chart suggestion, such as tornado chart or two-way table

Common sensitivity drivers:

- Adoption rate
- Benefit capture rate
- Baseline volume
- Unit margin or unit cost
- Implementation cost
- Time to scale
- Churn or retention impact
- Discount rate for multi-year cases

If data is missing, use ranges:

```text
Low case: conservative adoption and partial capture
Base case: expected adoption and realistic capture
High case: accelerated adoption and broader rollout
```

## Assumption Discipline

- Label every estimate as client-provided, benchmark, consultant assumption, or placeholder.
- Do not present rough estimates as guaranteed savings.
- Separate one-time benefits from recurring annual benefits.
- Separate gross benefit from net benefit after implementation cost.
- Include non-financial benefits when they materially support the decision.

## Industry Patterns

Retail and consumer:

- Revenue uplift from conversion, repeat purchase, basket size, retention, clienteling, loyalty, and campaign responsiveness
- Cost reduction from campaign operations, store support, manual reconciliation, and service handling
- Key metrics: repeat rate, conversion, active members, campaign cycle time, data accuracy, store adoption

SaaS and subscription:

- Revenue uplift from activation, expansion, retention, pricing, and sales productivity
- Cost reduction from onboarding automation, support deflection, and customer success efficiency
- Key metrics: ARR, NRR, churn, CAC payback, adoption, support tickets

Manufacturing and supply chain:

- Value from throughput, yield, downtime reduction, inventory turns, forecast accuracy, procurement savings, and quality cost reduction
- Key metrics: OEE, scrap rate, cycle time, OTIF, inventory days, working capital

Digital and IT:

- Value from avoided downtime, faster release cycles, reduced incidents, automation, data quality, vendor rationalization, and user productivity
- Key metrics: SLA attainment, incident volume, MTTR, deployment frequency, data accuracy, user satisfaction

Change management:

- Value from adoption speed, productivity retention, reduced disruption, compliance, capability building, and realization of transformation benefits
- Key metrics: adoption rate, training completion, proficiency, readiness, behavior change, benefits realization

## Commercial Framing

When proposing consulting fees or engagement options:

- Tie price to scope, team seniority, timeline, and deliverables.
- Avoid unnecessary discounting language.
- Offer options only if the client needs choice:
  - Essential: diagnosis and high-level roadmap
  - Recommended: diagnosis, design, and pilot support
  - Comprehensive: end-to-end transformation support
