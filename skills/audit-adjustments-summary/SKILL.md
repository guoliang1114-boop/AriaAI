# 审计调整汇总与未更正错报评估

## When To Use
- 需要汇总审计过程中发现的所有错报
- 编制审计调整分录并评估管理层是否接受调整
- 评估未更正错报对财务报表的影响
- 准备与管理层和治理层的沟通文件
- 在审计完成阶段评估财务报表整体是否公允反映

## Tools
- `search` — 搜索审计过程中识别的错报、调整分录
- `read` — 读取各科目实质性程序工作底稿、重要性水平
- `write` — 生成调整汇总表和管理层沟通函
- `edit` — 更新调整状态、修改错报评估

## Framework

### 错报分类框架（ISA 450第5条）
1. **事实错报（Factual Misstatements）** — 无争议的错报，需直接调整
2. **判断错报（Judgemental Misstatements）** — 因会计估计或政策选择差异产生
3. **推断错报（Projected Misstatements）** — 由审计抽样结果推断至总体的错报

### 重要性水平评估（ISA 320 / ISA 450）
1. 确定整体重要性水平（PM）
2. 确定实际执行的重要性（TE）
3. 确定明显微小错报临界值（SAD）
4. 将每项错报与重要性水平比较
5. 评估未更正错报汇总是否超过重要性水平

### 未更正错报评估步骤（ISA 450第11-13条）
1. 汇总所有已识别但未更正的错报
2. 评估每项错报的性质和原因
3. 考虑错报对特定账户、披露和财务报表整体的影响
4. 评估未更正错报是否导致财务报表存在重大错报
5. 考虑错报的定性因素（如关联方交易、持续经营等）

### 评估定性因素
- 错报是否影响管理层薪酬或业绩指标
- 错报是否涉及关联方交易的充分披露
- 错报是否影响债务契约的遵守
- 错报是否掩盖了收益或其他趋势的变化
- 错报是否影响财务报表使用者的经济决策

## Workflow
1. 收集各审计领域识别的所有错报
2. 按事实错报、判断错报、推断错报分类
3. 编制调整分录并提交管理层
4. 跟踪管理层对每项调整的回应（接受/拒绝）
5. 汇总未更正错报并评估其对财务报表的影响
6. 将未更正错报与重要性水平比较
7. 编制管理层和治理层沟通文件
8. 形成错报评估结论

## Diagnostic Questions
- 是否已收集所有审计领域识别的错报？
- 每项调整分录是否有明确的错报类型分类（事实/判断/推断）？
- 管理层拒绝调整的理由是否合理，是否有充分的审计证据支持审计师的立场？
- 未更正错报的定性因素是否已充分考虑（如管理层薪酬、债务契约、关联方交易）？
- 推断错报的计算是否基于样本结果合理推断至总体？
- 是否需要就未更正错报与治理层直接沟通？
- 错报是否涉及前期财务报表的追溯调整？

## Verification
- 核实调整分录借贷方金额的数学准确性
- 确认明显微小错报已正确筛选和排除
- 确认所有实质性程序发现的错报均已纳入汇总
- 验证管理层回应记录的完整性
- 复核重要性水平评估的合理性
- 确保未更正错报评估涵盖定性和定量因素
