# 税务合规日历管理

## When To Use

- 企业需要建立年度税务申报时间管理体系
- 新设企业首次进行税务申报规划
- 集团公司需要统一管理多家子公司的申报节点
- 年初制定全年税务工作计划
- 申报期限临近需要提醒和检查
- 税务管理人员交接需要梳理申报义务

## Tools

- `read` — 读取企业税种认定信息、历史申报记录
- `grep` — 搜索税种适用条件、申报期限规定
- `bash` — 生成日历文件、计算关键日期
- `webfetch` — 查询最新申报期限调整通知

## Framework

### 法律依据

| 法规 | 核心条款 |
|------|---------|
| 《税收征收管理法》 | 第25条 按期申报义务；第27条 延期申报 |
| 《增值税暂行条例》 | 第23条 申报期限 |
| 《企业所得税法》 | 第54条 按月/季预缴、年度汇算清缴 |
| 《个人所得税法》 | 第12条 综合所得汇算清缴 |
| 国家税务总局公告 | 各年度申报期限调整通知 |
| OECD Tax Administration 2023 | Filing and payment benchmarks |

### 主要税种申报期限

#### 月度申报（每月15日前）

| 税种 | 申报期限 | 适用对象 |
|------|---------|---------|
| 增值税（一般纳税人） | 次月15日前 | 一般纳税人 |
| 消费税 | 次月15日前 | 消费税纳税人 |
| 城市维护建设税 | 随增值税/消费税 | 增值税/消费税纳税人 |
| 教育费附加 | 随增值税/消费税 | 增值税/消费税纳税人 |
| 地方教育附加 | 随增值税/消费税 | 增值税/消费税纳税人 |
| 个人所得税（代扣代缴） | 次月15日前 | 扣缴义务人 |
| 印花税（按次/按月） | 次月15日前 | 合同签订方 |
| 环境保护税 | 次月15日前 | 直接排污企业 |

#### 季度申报（季后15日前）

| 税种 | 申报期限 | 适用对象 |
|------|---------|---------|
| 增值税（小规模纳税人） | 季后15日前 | 小规模纳税人 |
| 企业所得税（预缴） | 季后15日前 | 查账征收企业 |
| 房产税（按季） | 季后15日前 | 房产所有人 |
| 城镇土地使用税（按季） | 季后15日前 | 土地使用人 |

#### 年度申报

| 税种 | 申报期限 | 特殊要求 |
|------|---------|---------|
| 企业所得税汇算清缴 | 次年5月31日前 | 需附送年度纳税申报表及附表 |
| 个人所得税综合所得汇算 | 次年3月1日-6月30日 | 年收入超12万或补税超400元 |
| 个人所得税经营所得汇算 | 次年3月31日前 | 查账征收的个体工商户 |
| 房产税（从价计征） | 5月/11月（各地不同） | 依当地规定 |
| 城镇土地使用税 | 5月/11月（各地不同） | 依当地规定 |
| 年度关联业务往来报告 | 次年5月31日前 | 关联交易企业 |
| 企业年度报告（市场监管） | 次年6月30日前 | 所有企业 |

### 特殊时点

- **1月**：上年第四季度企业所得税预缴申报
- **3月**：个税综合所得汇算开始；经营所得汇算截止
- **5月**：企业所得税汇算清缴截止；关联业务报告截止
- **6月**：个税汇算截止；企业年报截止
- **10月**：第三季度企业所得税预缴；部分地区房产税申报
- **12月**：年度税务自查、次年税务规划启动

### 逾期申报后果

- 滞纳金：每日万分之五（征管法第32条）
- 罚款：2000元以下；情节严重2000-10000元（征管法第62条）
- 纳税信用扣分：影响信用等级评定
- 发票限制：可能被限制开票

## Workflow

1. **税种确认**：根据企业税务登记信息确认应申报税种
2. **期限计算**：确定各税种的具体申报截止日（含法定节假日顺延）
3. **日历生成**：按月/季/年生成完整合规日历
4. **风险标记**：标记容易遗漏的申报事项和特殊时点
5. **提醒设置**：建议设置提前7天/3天/1天的三级提醒
6. **年度更新**：每年初更新日历，纳入政策变化

## Diagnostic Questions

- 企业属于一般纳税人还是小规模纳税人？
- 是否涉及消费税应税产品？
- 是否存在关联交易需要报送关联业务报告？
- 是否适用按季申报的简化政策？
- 是否有跨地区经营的分支机构需要汇总纳税？
- 是否享受需要备案的税收优惠？

## Verification

- 核对税务登记信息中的税种认定
- 确认当地税务机关的具体申报要求（各地可能有差异）
- 验证法定节假日顺延日期
- 检查是否有特殊行业的额外申报要求

## Saving

- 将日历保存至项目的 `output/` 目录
- 文件命名：`tax-calendar-{企业名称}-{YYYYMMDD}.md`
- 建议导出为 .ics 格式导入日历系统

## Capability Upgrade

### Mode Selection

- **Quick**: 输出未来 30/60/90 天申报提醒。
- **Standard**: 输出全年税务合规日历、责任人、申报频率和资料要求。
- **Deep**: 结合行业、地区、多主体、税种、优惠和历史逾期记录，形成可运营的合规管理机制。

### Calendar Logic

| 维度 | 处理规则 |
|------|----------|
| 主体 | 按法人、分支机构、项目公司分别列示 |
| 税种 | 区分月报、季报、年报、一次性事项 |
| 地区 | 标注地方税费、节假日顺延和地方口径 |
| 责任 | 每项申报有准备人、复核人、审批人 |
| 风险 | 高风险节点提前设置二次提醒 |

### Quality Gates

- [ ] 日期使用具体年月日，不只写“次月”或“季度后”。
- [ ] 节假日顺延和地方差异已标注。
- [ ] 每项申报有资料来源、责任人和提前准备时间。
- [ ] 年度事项如汇算清缴、关联申报、同期资料已覆盖。
- [ ] 输出可转为任务、日历或项目待办。
