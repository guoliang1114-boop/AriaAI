# 其他间接税合规评估

## When To Use

- 企业涉及消费税应税消费品的生产、委托加工或进口
- 需要梳理印花税应税凭证及税率适用
- 房产税的计税依据确定及优惠政策适用
- 城市维护建设税、教育费附加的合规计算
- 间接税整体合规性审查及优化

## Tools

- 国家税务总局税收法规库
- 消费税税目税率表
- 印花税税目税率表（2022年7月1日起施行新印花税法）
- 房产税计税依据及优惠政策查询
- 土地增值税清算工具

## Framework

### 消费税（《消费税法》2020年）

**税目及税率**：
- 烟（甲类卷烟56%+0.003元/支，乙类卷烟36%+0.003元/支）
- 酒（白酒20%+0.5元/500g，啤酒250元/吨或220元/吨）
- 高档化妆品15%、贵重首饰及珠宝玉石5%-10%
- 成品油（从量定额）、小汽车1%-40%、高尔夫球及球具10%
- 游艇10%、高档手表20%、电池4%、涂料4%

**计税方式**：
- 从价定率：应纳税额 = 销售额 × 比例税率
- 从量定额：应纳税额 = 销售数量 × 定额税率
- 复合计税：应纳税额 = 销售额 × 比例税率 + 销售数量 × 定额税率

### 印花税（《印花税法》2022年）

**税目及税率**：
- 借款合同0.005%、融资租赁合同0.005%
- 买卖合同0.03%、承揽合同0.03%
- 建设工程合同0.03%、运输合同0.03%
- 技术合同0.03%、租赁合同0.1%
- 保管合同0.1%、仓储合同0.1%
- 财产保险合同0.1%
- 产权转移书据0.05%（股权转让）/ 0.1%（不动产转让）
- 营业账簿0.025%

### 房产税

- **从价计征**：房产原值一次减除10%-30%后的余值，税率1.2%
- **从租计征**：租金收入，税率12%（个人出租住房4%）
- **优惠政策**：小规模纳税人减半征收、保障性住房免征等

### 城市维护建设税

- 纳税人所在地在市区：7%
- 县城、镇：5%
- 其他地区：1%
- 计税依据：实际缴纳的增值税、消费税税额
- 2021年9月1日起，进口货物缴纳增值税/消费税不附征城建税

## Workflow

```
1. 税种适用性判定
   ├─ 消费税：应税消费品识别
   ├─ 印花税：应税凭证梳理
   ├─ 房产税：应税房产识别
   └─ 其他：城建税、教育费附加等

2. 计税依据分析
   ├─ 消费税：销售额/销售数量确定
   ├─ 印花税：合同金额/凭证性质
   ├─ 房产税：原值/余值/租金
   └─ 优惠政策适用性

3. 合规风险识别
   ├─ 税目税率适用错误
   ├─ 计税依据不完整
   ├─ 优惠政策未享受
   └─ 申报期限延误

4. 优化方案设计
   ├─ 业务模式调整降低税负
   ├─ 优惠政策的充分利用
   ├─ 纳税时点优化
   └─ 关联交易定价优化

5. 合规整改
   ├─ 补税/退税测算
   ├─ 申报表修正
   └─ 内控制度完善
```

## Diagnostic Questions

1. 企业是否生产、委托加工或进口应税消费品？
2. 主要签订哪些类型的合同？是否有合同管理台账？
3. 自有房产和租赁房产的情况？是否有房产原值的完整记录？
4. 是否享受小规模纳税人"六税两费"减半征收优惠？
5. 是否存在关联方之间的应税交易？
6. 近三年是否接受过税务检查？是否有补税记录？

## Verification

- 核对消费税应税消费品与税目税率表的一致性
- 验证印花税计税依据是否包含增值税
- 确认房产税计税原值是否完整（含附属设备）
- 检查城建税税率与纳税人所在地的一致性
- 比对各税种申报数据与财务数据
