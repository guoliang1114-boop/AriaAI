# 海关与贸易合规评估

## When To Use

- 进出口货物的海关估价争议或优化
- HS编码归类不确定或面临海关质疑
- 原产地证书的申请及关税优惠适用
- 自贸区/综合保税区业务模式设计
- 海关稽查应对及合规自查

## Tools

- 中国海关总署HS编码查询系统
- 原产地证书申请及查询系统
- 关税税率查询（最惠国/协定/暂定税率）
- 海关估价数据库（成交价格/相同货物/类似货物）

## Framework

### 《中华人民共和国海关法》及《关税法》

**海关估价（WTO海关估价协定 / 中国海关法第55条）**：
- 六种估价方法按顺序适用：
  1. 成交价格法（Transaction Value）
  2. 相同货物成交价格法
  3. 类似货物成交价格法
  4. 倒扣价格法
  5. 计算价格法
  6. 合理方法（Reasonable Means）

**成交价格的调整项目**：
- 应计入：佣金和经纪费、容器费用、包装材料和劳务费用、特许权使用费、转售收益
- 可扣除：建设/安装/装配/维修/技术援助费用、运输及保险费用（CIF/FOB转换）

### HS编码归类规则

依据《商品名称及编码协调制度》归类总规则（GRI）：
- **规则一**：品目条文及注释具有法律效力
- **规则二**：不完整品/未制成品按完整品/制成品归类；混合物/组合物按基本特征归类
- **规则三**：从后归则、基本特征、最具体品目
- **规则四**：最相类似
- **规则五**：包装容器
- **规则六**：子目归类

### 原产地规则

- **完全获得标准**（WO）：货物完全在一个国家获得或生产
- **实质性改变标准**：
  - 税则归类改变（CTC/CTH）
  - 区域价值成分（RVC，通常要求40%以上）
  - 加工工序标准
- **中国自贸协定**：RCEP、中国-东盟、中国-韩国、中国-澳大利亚等

## Workflow

```
1. 基本信息收集
   ├─ 货物名称、规格、用途、材质
   ├─ 进出口口岸、贸易方式
   ├─ 成交方式（FOB/CIF/EXW）
   └─ 关联方交易情况

2. HS编码归类
   ├─ 品目注释及子目注释分析
   ├─ 归类总规则逐条适用
   ├─ 海关预归类决定查询
   └─ 归类风险评估

3. 海关估价分析
   ├─ 成交价格的确认与调整
   ├─ 特许权使用费的计入判定
   ├─ 关联方交易价格的公允性
   └─ 估价风险评估

4. 原产地及关税优化
   ├─ 适用自贸协定的判定
   ├─ 原产地规则的满足情况
   ├─ 关税税差比较
   └─ 原产地证书申请方案

5. 保税/自贸区方案
   ├─ 综合保税区政策适用
   ├─ 保税加工/保税物流模式
   ├─ 区内交易税务处理
   └─ 合规风险评估
```

## Diagnostic Questions

1. 企业的主要进出口商品是什么？是否有归类争议？
2. 进出口交易是否涉及关联方？
3. 是否有特许权使用费与进口货物相关？
4. 目前是否已利用自贸协定优惠关税？
5. 是否有综合保税区或其他保税区域的业务？
6. 近三年是否接受过海关稽查？结果如何？

## Verification

- 核对HS编码与海关预归类决定的一致性
- 验证成交价格的调整项目是否完整
- 确认原产地证书的真实性和有效性
- 检查保税账册的准确性
- 比对申报价格与独立交易价格
