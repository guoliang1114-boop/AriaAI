# 并购后税务整合

## When To Use

- 完成并购交易后需要进行税务整合
- 目标公司存在未弥补亏损需要规划利用
- 需要调整集团税务架构以实现协同效应
- 并购后业务重组涉及税务优化
- 需要评估并购交易的税务协同价值

## Tools

- 税务尽职调查报告
- 集团组织架构图
- 目标公司历年纳税申报表
- 并购交易协议及对价分配方案
- 关联交易台账

## Framework

### 一、税务协同效应识别

1. **间接抵免协同**：根据《企业所得税法》第24条，居民企业从其直接或间接持有20%以上股份的外国企业取得的股息红利，可抵免境外已纳税款
2. **增值税进项税额整合**：并购后统一管理进项税额，优化增值税链条
3. **亏损结转利用**：被合并企业亏损在满足条件时可由合并企业承继
4. **关联交易定价优化**：整合后重新规划集团内部转移定价策略

### 二、亏损结转利用（中国EIT法）

根据《财政部 税务总局关于企业重组业务企业所得税处理若干问题的通知》（财税〔2009〕59号）：

- **一般性税务处理**：被合并企业亏损不得结转至合并企业
- **特殊性税务处理**：合并企业可弥补被合并企业亏损，但有限额限制
  - 可弥补亏损额 = 被合并企业净资产公允价值 × 截至合并业务发生当年年末国家发行的最长期限的国债利率
- **适用条件**：
  - 股权支付比例不低于85%
  - 合理商业目的
  - 12个月内不改变被合并企业原有实质性经营活动

### 三、集团税务架构调整

1. **控股架构优化**：评估是否需要调整持股层级以适用间接抵免
2. **功能定位调整**：根据并购后业务整合情况，重新确定各实体的功能风险定位
3. **资产/负债转移**：评估资产划转的税务成本，选择最优方案（划转/转让/出资）
4. **区域优惠利用**：评估是否可通过注册地迁移享受区域税收优惠

### 四、国际标准参考

- OECD Transfer Pricing Guidelines Chapter I-III：关联交易定价基本原则
- OECD Model Tax Convention Article 9：关联企业利润调整
- UN Tax Convention：发展中国家间税收协调

## Workflow

1. 收集并购交易文件及目标公司税务资料
2. 分析目标公司税务状况（亏损、优惠、风险）
3. 识别可实现的税务协同效应
4. 设计集团税务架构调整方案
5. 测算亏损结转利用的税务效益
6. 制定关联交易定价调整策略
7. 编制整合时间表及责任分工
8. 输出完整的税务整合方案

## Diagnostic Questions

1. 并购交易是否适用特殊性税务处理？
2. 目标公司是否存在未弥补亏损？亏损金额及到期时间？
3. 并购后集团控股架构是否需要调整？
4. 是否存在跨境关联交易需要重新定价？
5. 目标公司是否享受税收优惠？优惠是否可延续？
6. 是否涉及资产划转或股权划转？

## Verification

- 核实亏损结转的法律依据及限额计算
- 验证特殊性税务处理的适用条件
- 确认架构调整的税务成本测算
- 审核关联交易定价的合规性
- 评估方案实施的可行性

## Capability Upgrade

### Mode Selection

- **Quick**: 根据交易背景输出并购后税务整合重点清单。
- **Standard**: 输出亏损利用、税务架构、转让定价、税务协同和实施计划。
- **Deep**: 结合交易协议、税务尽调、SPA 条款、交割清单和目标公司历史申报，形成 100 天税务整合方案和协同追踪机制。

### Aria Context Enrichment

优先读取项目中的税务尽调报告、交易结构图、SPA、财务模型、组织架构图、目标公司税务台账和客户历史偏好。若资料缺失，先输出资料缺口清单，并标注哪些判断只能作为假设。

### Integration Decision Logic

| 整合主题 | 判断问题 | 交付结果 |
|----------|----------|----------|
| 亏损结转 | 是否满足特殊性税务处理、限额和连续经营要求 | 亏损利用测算和风险提示 |
| 税务架构 | 是否需要合并纳税主体、调整控股层级或区域布局 | 架构调整方案和税务成本 |
| 转让定价 | 功能风险是否改变、关联交易是否新增 | 转让定价政策调整清单 |
| 优惠延续 | 高新、地方优惠、亏损、递延税项能否保留 | 优惠延续判断表 |
| 交割后合规 | 是否存在申报、备案、发票、合同主体切换 | Day 1 / Day 30 / Day 100 清单 |

### Synergy Quantification

协同收益必须分层披露：

- **已确认收益**：有法规依据、资料完整、可测算。
- **待验证收益**：需要税局沟通、补充资料或管理层决策。
- **不建议计入收益**：法律依据弱、执行成本高或风险不可控。

### Quality Gates

- [ ] 特殊性税务处理条件逐项验证，不只写结论。
- [ ] 税务协同收益区分现金节税、递延节税和风险降低。
- [ ] 每项架构调整都有实施步骤、责任人、时间点和备案要求。
- [ ] 已识别交割后 100 天内必须完成的税务事项。
- [ ] 与交易协议中的税务赔偿、陈述保证和价格调整机制一致。
