# 税务争议应对

## When To Use

- 企业收到税务稽查通知书或纳税评估约谈通知
- 税务机关发起反避税调查（特别纳税调整）
- 税务行政复议或行政诉讼的准备
- 重大税务事项的事前裁定申请
- 关联交易被质疑定价不合理
- 历史遗留税务问题的主动披露

## Tools

- `read` — 读取税务机关通知文件、企业账簿、合同
- `grep` — 搜索相关法律条文、判例、政策文件
- `bash` — 整理证据材料清单、计算补税/滞纳金金额
- `webfetch` — 查询最新税务争议案例和政策解读

## Framework

### 法律依据

| 法规 | 核心条款 |
|------|---------|
| 《税收征收管理法》 | 第54条 税务检查权；第63条 偷税认定；第88条 复议前置 |
| 《税收征收管理法实施细则》 | 第98条 纳税人权利义务 |
| 《税务稽查工作规程》（国税发〔2009〕157号） | 稽查程序规范 |
| 《特别纳税调整实施办法》（国税发〔2009〕2号） | 反避税调查程序 |
| 《税务行政复议规则》（国家税务总局令第39号） | 复议程序 |
| 《行政处罚法》 | 第32条 陈述申辩权；第42条 听证权 |
| OECD Transfer Pricing Guidelines (2022) | Chapter IV: Administrative Dispute Resolution |

### 税务稽查应对策略

**稽查类型：**
- 日常稽查：随机选案
- 专项稽查：行业性、区域性专项整治
- 专案稽查：举报、协查线索

**应对时间线：**
1. 收到通知 → 3日内启动内部响应机制
2. 资料准备 → 7日内完成自查并整理证据
3. 现场检查 → 配合但审慎回答
4. 稽查结论 → 15日内提出陈述申辩
5. 处理决定 → 60日内可申请行政复议

### 纳税评估应对

**评估流程：**
- 税务机关通过数据分析发现异常指标
- 约谈纳税人说明情况
- 纳税人提供举证材料
- 评估结论：无问题/自查补税/移送稽查

**应对要点：**
- 及时响应约谈，避免被视为不配合
- 准备充分的解释材料和佐证文件
- 关注税负率、毛利率、费用率等异常指标的合理解释

### 反避税调查应对

**触发条件：**
- 关联交易不符合独立交易原则
- 受控外国企业（CFC）利润不分配
- 资本弱化（债资比超过标准）
- 一般反避税安排（GAAR）

**应对策略：**
- 准备同期资料（本地文档、主体文档、国别报告）
- 申请预约定价安排（APA）
- 选择合理转让定价方法（CUP/成本加成/交易净利润法/利润分割法）

### 证据准备清单

- 原始合同、协议及补充协议
- 银行流水、收付款凭证
- 发票及发票台账
- 内部审批流程文件
- 关联交易同期资料
- 第三方评估报告（如适用）
- 行业惯例和可比交易数据

## Workflow

1. **情况评估**：了解争议性质、涉及税种、金额、时间跨度
2. **风险分级**：将争议按金额和性质分为高/中/低风险
3. **策略制定**：根据争议类型选择应对策略（配合/申辩/复议/诉讼）
4. **证据梳理**：整理和补充证据材料
5. **模拟演练**：预演税务机关可能的提问和质疑
6. **正式应对**：参与约谈、提交材料、陈述申辩
7. **后续跟踪**：监控处理进展，必要时启动救济程序

## Diagnostic Questions

- 税务机关以什么形式通知（电话/书面/约谈）？
- 涉及的具体税种和期间是什么？
- 是否有被认定为偷税的风险（影响罚款倍数和刑事责任）？
- 关联交易是否已准备同期资料？
- 是否存在历史遗留问题需要主动披露？
- 企业是否具备税务行政复议前置条件？

## Verification

- 确认法律依据的有效性和时效性
- 验证证据材料的完整性和关联性
- 评估应对策略的可行性和风险收益比
- 检查时间节点是否满足法定期限要求

## Saving

- 将方案保存至项目的 `output/` 目录
- 文件命名：`tax-dispute-strategy-{企业名称}-{YYYYMMDD}.md`
- 敏感信息需脱敏处理，证据原件另行保管

## Capability Upgrade

### Mode Selection

- **Quick**: 判断争议性质、风险等级和下一步回应。
- **Standard**: 输出争议焦点、证据清单、沟通策略、时间线和应对方案。
- **Deep**: 结合稽查通知、约谈记录、申报资料、合同、凭证和税局观点，形成复议/诉讼前策略包。

### Dispute Path Decision

| 路径 | 适用条件 | 风险 |
|------|----------|------|
| 主动说明和补充证据 | 事实清楚、证据可补强 | 需控制口径 |
| 沟通协商 | 争议点可解释、金额可控 | 可能形成不利承诺 |
| 行政复议 | 法律适用或程序存在争议 | 时间和资料要求高 |
| 行政诉讼 | 重大金额或原则性争议 | 周期长、公开性高 |

### Quality Gates

- [ ] 法定期限、回复期限和救济期限明确。
- [ ] 证据清单区分已有、待补、难以取得。
- [ ] 与税局沟通口径避免承认未验证事实。
- [ ] 策略同时考虑金额、声誉、后续年度和集团影响。
- [ ] 敏感资料有脱敏和访问控制要求。
