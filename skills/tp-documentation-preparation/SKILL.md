# 转让定价文档准备

## When To Use

- 企业需要准备年度转让定价文档
- 关联交易金额达到同期资料准备门槛
- 跨国企业集团需要报送国别报告
- 税务机关要求提供转让定价资料
- 企业关联交易政策发生重大变化

## Tools

- 企业财务报表及审计报告
- 关联交易台账及合同
- 集团组织架构图
- 功能风险分析问卷
- 可比公司数据库（Bureau van Dijk、Wind等）

## Framework

### 一、OECD BEPS Action 13 三层文档体系

#### 1. 主体文档（Master File）

根据OECD BEPS Action 13指引，主体文档应包含：

- **集团组织架构**：全球法律实体及经营实体架构图
- **集团业务描述**：主要业务活动、重要价值驱动因素
- **无形资产**：集团无形资产组合、转让定价政策
- **关联交易活动**：集团内关联交易概览
- **集团财务状况**：合并财务报表、关联交易金额汇总
- **税务状况**：集团预约定价安排、税务裁定信息

#### 2. 本地文档（Local File）

- **本地实体信息**：管理架构、经营战略、主要竞争者
- **关联交易详情**：关联交易类型、金额、对手方
- **功能风险分析**：本地实体承担的功能、风险及资产
- **转让定价方法**：选用的定价方法及理由
- **可比性分析**：可比公司筛选、财务指标分析
- **基准测试结果**：转让定价区间及合规性结论

#### 3. 国别报告（Country-by-Country Report）

- **Table 1**：各税收管辖区收入、利润、税款、员工等汇总数据
- **Table 2**：各税收管辖区实体清单及主要业务活动
- **Table 3**：附加说明

### 二、中国特定要求（国家税务总局公告2016年第42号）

#### 同期资料准备门槛

- **主体文档**：年度关联交易金额超过10亿元
- **本地文档**：
  - 有形资产转让金额（来料加工按进出口报关价格计算）超过2亿元
  - 金融资产转让金额超过1亿元
  - 无形资产所有权转让金额超过1亿元
  - 其他关联交易金额合计超过4000万元
- **国别报告**：跨国企业集团合并收入超过55亿元

#### 中国本地文档特殊要求

- 需包含价值链分析（全球价值链贡献分析）
- 需包含地域特殊优势分析（Location-Specific Advantages）
- 需提供关联交易合同清单及定价政策说明
- 需包含对外投资情况说明

### 三、转让定价方法（OECD Guidelines Chapter II）

| 方法 | 适用场景 | 优先级 |
|------|----------|--------|
| 可比非受控价格法（CUP） | 存在高度可比交易 | 最优 |
| 再销售价格法（RPM） | 分销商无实质性加工 | 次优 |
| 成本加成法（COST+） | 制造商/服务提供商 | 常用 |
| 交易净利润法（TNMM） | 功能简单的实体 | 最常用 |
| 利润分割法（PSM） | 双方均贡献独特价值 | 特殊场景 |

## Workflow

1. 收集企业财务数据及关联交易明细
2. 进行功能风险分析，确定企业角色定位
3. 选择适当的转让定价方法
4. 筛选可比公司并进行财务分析
5. 计算基准测试区间
6. 撰写主体文档、本地文档
7. 准备国别报告（如适用）
8. 内部审核及定稿

## Diagnostic Questions

1. 企业年度关联交易总额是多少？是否达到同期资料准备门槛？
2. 企业属于集团内何种功能定位（制造商/分销商/服务提供商）？
3. 集团是否已在中国以外准备主体文档？
4. 是否存在特殊关联交易类型（如技术许可、品牌使用）？
5. 集团是否已有预约定价安排？
6. 企业是否享受高新技术企业优惠税率？

## Verification

- 核实关联交易金额与财务报表一致性
- 验证可比公司筛选标准的合理性
- 确认转让定价方法选择的适当性
- 审核功能风险分析的完整性
- 检查文档格式是否符合42号公告要求

## Saving

- 保存路径：`projects/{project-name}/tp-documentation/`
- 文件命名：`tp-doc-{entity}-{year}.md`
- 关联文件：财务报表、关联交易合同、可比公司分析表

## Capability Upgrade

### Mode Selection

- **Quick**: 判断是否达到同期资料准备门槛，并列出所需资料。
- **Standard**: 生成主体文档、本地文档或国别报告的大纲和资料清单。
- **Deep**: 结合财务报表、关联交易合同、集团架构、功能风险访谈和可比公司筛选，形成完整转让定价文档包。

### Documentation Boundary Logic

| 文档类型 | 触发条件 | 重点内容 |
|----------|----------|----------|
| 主体文档 | 集团层面信息或达到门槛 | 集团组织、业务、无形资产、融资、财务税务状况 |
| 本地文档 | 中国实体关联交易达到门槛 | 关联交易、功能风险、定价方法、可比分析 |
| 特殊事项文档 | 成本分摊、资本弱化、受控外国企业等 | 特殊交易背景、定价逻辑、合规证明 |
| 国别报告 | 达到集团收入门槛 | 税收、收入、利润、员工、实体活动 |

### Transfer Pricing Analysis Model

1. 识别关联交易类型和金额。
2. 判断企业功能风险定位。
3. 选择最合适转让定价方法。
4. 建立可比性筛选标准。
5. 判断利润水平是否落入四分位区间。
6. 对异常结果提出调整或解释。

### Quality Gates

- [ ] 关联交易金额与财务报表、申报表和合同一致。
- [ ] 功能、风险、资产分析能支持企业角色定位。
- [ ] 定价方法选择说明为什么不用其他方法。
- [ ] 可比公司筛选标准可复核，剔除理由清楚。
- [ ] 文档结论与企业税收优惠、亏损、特殊交易没有冲突。
