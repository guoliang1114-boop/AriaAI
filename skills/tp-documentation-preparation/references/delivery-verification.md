# 交付验证：tp-documentation-preparation

涉及法规、税率、申报期限和准则的判断，执行时查明适用法域、期间及当前一手来源；本包中的历史数字与举例不能自动作为现行依据。把原文、推断、客户陈述和待证实事项分开。

## 必须取得的检查证据

1. 功能资产风险分析对应实际经营证据。
2. 定价方法、利润指标及可比性筛选一致。
3. 报告义务、门槛和期限按法域与期间核实。

## 复核记录

按检查项记录输入位置/文件版本、实际计算或输出位置、通过/不通过/待补证、复核日期。未通过项需给出影响和修复动作，不得仅以章节齐全判定合格。

用 [合成案例](../examples/delivery-case.md) 进行对照；案例是预期行为规范，不是已经执行成功的证明。
