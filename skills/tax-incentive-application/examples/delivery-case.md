# 合成交付案例：tax-incentive-application

本例不包含客户数据；数字仅为测试输入。

## 输入

企业有研发支出 100，混有生产成本及关联委托研发，要求全部享受优惠。

## 预期交付与判断

- 按活动和凭证区分候选合格支出与待核验支出。
- 先评估主体、期间及优惠条件，暂不输出确定优惠额。
- 呈现费用归集、证明材料和申报路径。

## 验收方法

逐项核对上述判断与 [交付检查](../references/delivery-verification.md)，记录实际答案或文件及每项检查的证据。缺少任一判断、编造事实、越权写入或虚构工具成功，均不通过。

## 变体
