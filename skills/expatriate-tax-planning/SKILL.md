# 外籍人员税务筹划

## When To Use

- 企业派遣员工赴中国或从中国派遣至境外工作
- 外籍个人在华取得所得需进行税务规划
- 需要判定税收居民身份及适用税收协定待遇
- 跨境社保缴纳安排优化
- 境外已纳税额的税收抵免计算

## Tools

- 双边税收协定数据库（国家税务总局）
- 社保缴纳基数及费率查询
- IIT计算器（综合所得/分类所得）
- 外汇管理局跨境支付规则查询

## Framework

### OECD Model Tax Convention

依据OECD范本及UN范本，确定跨境所得的征税权分配：

- **Article 15** — 受雇所得：183天规则、报酬由居民国雇主支付、常设机构负担
- **Article 16** — 董事费
- **Article 19** — 政府服务
- **Article 23** — 消除双重征税方法（抵免法/免税法）

### 中国个人所得税法（2018修订）

- **居民个人**：在中国境内有住所，或无住所而一个纳税年度内在中国境内居住累计满183天
- **非居民个人**：无住所且不满足上述条件
- **六年规则**：无住所个人连续六年满足居民条件且未单次离境超30天，全球征税；否则仅就境内所得及境外所得境内支付部分征税（财税〔2019〕35号）

### 社会保障双边协定

中国已与德、韩、丹、芬、加、日等国签署社保互免协定。协定通常规定：
- 派遣期限（通常24-60个月）内可继续在母国缴纳社保
- 需开具参保证明

## Workflow

```
1. 事实收集
   ├─ 派遣期限、岗位、薪酬结构
   ├─ 出入境记录（183天计算）
   └─ 母国社保及税务状况

2. 居民身份判定
   ├─ 住所标准（户籍、家庭、经济利益中心）
   ├─ 183天居住天数计算
   └─ 六年规则适用性

3. 所得性质分类
   ├─ 工资薪金（境内/境外支付）
   ├─ 数月奖金/股权激励
   ├─ 董事费、顾问费
   └─ 住房、子女教育等实物福利

4. 协定待遇分析
   ├─ 适用条款识别
   ├─ 征税权分配
   └─ 抵免限额计算

5. 筹划方案设计
   ├─ 薪酬结构优化（现金vs实物）
   ├─ 派遣模式选择（个人派遣vs公司派遣）
   ├─ 社保互免申请
   └─ 税收抵免安排
```

## Diagnostic Questions

1. 员工是否在中国境内有住所（户籍、房产、家属）？
2. 过去6个纳税年度在华居住天数分别是多少？
3. 薪酬由哪一方支付？境内还是境外实体？
4. 是否已适用社保双边互免协定？
5. 母国对该员工的税务立场如何？
6. 是否涉及股权激励或递延薪酬？

## Verification

- 核对出入境记录（护照盖章/出入境管理局记录）
- 验证183天计算的完整性（含入境日、离境日）
- 确认税收协定文本的适用版本
- 核实社保互免证明的有效期
- 比对实际税负与测算差异

## Capability Upgrade

### Mode Selection

- **Quick**: 判断居民身份、183 天风险和基本税负方向。
- **Standard**: 输出居民身份、协定待遇、社保、薪酬拆分和税负测算。
- **Deep**: 针对派遣、跨境高管、股权激励或多国任职，形成多方案税务规划、雇主合规义务和年度行动日历。

### Aria Context Enrichment

优先读取员工派遣协议、劳动合同、薪酬结构、出入境记录、股权激励文件、母国税务居民证明和公司跨境派遣政策。若涉及客户长期合作，应结合客户偏好判断是否偏向保守合规、税负优化或员工体验。

### Residency and Treaty Decision Tree

```text
是否在中国有住所？
├── 是 → 通常按中国税收居民分析全球所得，并评估六年规则
└── 否 → 计算中国境内居住天数
    ├── <90天/183天协定门槛 → 判断雇主支付与常设机构承担
    ├── ≥183天 → 重点评估中国征税权、境外税收抵免
    └── 跨年度派遣 → 逐年计算，不能只看合同期间
```

### Quality Gates

- [ ] 出入境天数逐日或逐月核对，并说明口径。
- [ ] 协定适用必须说明条款、条件和资料要求。
- [ ] 税负测算区分员工个人负担和雇主总成本。
- [ ] 股权激励、奖金和补贴没有被遗漏。
- [ ] 给出年度日历，明确申报、备案、证明和沟通节点。
